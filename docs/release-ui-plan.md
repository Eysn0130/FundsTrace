## 1. 工作方式与目标

- 使用默认施工模式，以“有界接管 → 用户流程审计 → 更新执行计划 → 实现 → 浏览器复验 → 发布候选交付”推进；不在纯 Plan 模式中停留，也不在完成计划后等待重复开工许可。

- 从实际使用者完成资金追踪任务的过程检查界面：能找到、能看清、能操作、能理解结果、能恢复错误。
- 新增两个已授权交互：查询表单独立折叠，以及可连续选择并即时上图的居中流水全览。
- 全面检查现有功能入口、控件内部字体与SVG、焦点、反馈、所有空间动画和遮罩交互。源码、浏览器、桌面包、Windows实机和正式发布证据分别记录。

## 3. 设计依据与 Skill 分工

### 已确认的视觉依据

确认的展开、侧栏收起和紧凑设计已复制到本地忽略证据目录 `output/release-ui/reference-*.png`。生成图中的账户、金额、统计和不存在的控件均不作为业务契约。

### Apple 与 open-claude-ui 的适用原则

- [Apple Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)：常用任务保持可达，细节渐进展开。查询折叠后留下条件摘要与结果数。
- [Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)：多列数据仍用表格，优先保证列关系、阅读、选择和滚动。
- [Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)、[Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)：本轮全览是即时生效的数据工作区，不设置“确认应用”页脚；点外关闭保留已完成操作。真正模态时必须具有焦点管理，不能只添加aria-modal。
- [Focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection)、[Undo and redo](https://developer.apple.com/design/human-interface-guidelines/undo-and-redo)：焦点、勾选、已上图三种状态需要明确；反复发生的可撤销操作不增加确认框。
- [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：动效解释空间与状态，支持减少动态效果、清晰焦点和文字/图形辅助反馈。
- [open-claude-ui](https://github.com/Caho1/open-claude-ui) 只借鉴分层表面、紧凑折叠头与键盘漫游思路。前置研究快照为 `2834bc158a4849f21c97cbb2e0b10525f6e646f1`；其 `ThinkingAccordion.tsx` 生成中强制展开及可点击div不适合这里；`ConfirmationDialog.tsx` 的同步onConfirm/onClose、缺少完整焦点管理不能直接套到异步上图。主题配色、品牌和强动画不照搬。

### 工具选择

- Product Design `audit`：先捕获实际流程，再提出问题；`design-qa`：候选与确认图同视口、同状态并排对照。
- [Impeccable](https://github.com/pbakaus/impeccable)：精修、统一、反馈和动效的主参考。读取所用版本的实际Skill，不凭记忆假装执行命令。
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)：字体、色彩、密集表格与可访问性规则的查阅参考；不另起一套设计语言。
- [Taste](https://github.com/Leonxlnx/taste-skill)：审美复核，重点检查模板化、杂乱与层级；不覆盖已经确认的工作台方向。
- 使用现有前端/浏览器技能和项目测试入口。图标继续选用有许可的本地Tabler轮廓体系；不下载SF Symbols充当跨平台图标，也不画近似品牌资产。
- 热度作为候选筛选信号，记录来源日期；不能宣称完成全GitHub排名或以star代替适配性。避免同时安装多套CLI、引入大型运行依赖或上传私有项目内容到外部设计服务。

## 4. 新交互的明确契约

### A. 查询表单独立折叠

1. 左侧整体开关、顶部工具带开关、查询表单开关彼此独立。
2. 查询区使用原生button，`aria-expanded` / `aria-controls`完整。收起后保留“筛选”标题、有效条件摘要、结果数与展开入口；进行中也能折叠。
3. 仅折叠查询字段，表格工具、批量操作、全览入口和结果分页继续可达；不能连同追踪入口一起隐藏。
4. 条件值、查询结果、页码、批量勾选和表格滚动位置保留；折叠本身不重新查询、不改变追踪集合。
5. 先用折叠解决高度；竖向拖动分割线仅在审计证明有必要时增加，避免同一空间出现多套竞争手势。
6. 过渡可中断、可反向，完成后表格获得实际高度；键盘焦点不留在hidden/inert字段。减少动态效果时取消空间动画。

### B. 居中流水全览

1. 在表格工具区提供“展开流水表”SVG图标按钮，具备清晰名称、tooltip与键盘入口。图标不靠文字字符模拟。
2. 中央大视图有标题、当前案件/画布、结果数、上图状态、关闭按钮；表头与工具区固定、表体独立滚动。宽屏尽量同屏展示7列，保留完整金额、账号和必要局部横滚。
3. 不设置“确定/应用/取消”页脚；多次勾选期间保持打开。点真正的外部遮罩、关闭按钮或Escape均只关闭视图，不撤销已经完成的操作。
4. 遮罩pointerdown/pointerup都必须发生在遮罩才关闭，防止行内拖选、滚动条拖动后误关闭；关闭事件不穿透至画布。处理嵌套菜单、IME组合、详情入口及原生文件对话框的层级。
5. 初始焦点、焦点边界和关闭还焦完整，焦点不可落到隐藏内容。关闭后回到原“展开流水表”按钮。
6. 侧栏和全览共享同一案件/画布绑定的查询结果与追踪事实。优先复用表格DOM/数据入口，必要时用同一模型渲染；不复制一套API与业务逻辑，不产生重复DOM id。
7. 侧栏原“批量选择”保留其锚点选择语义；全览第一列明确命名“上图”，勾选表示当前画布已上图状态。两个概念分别建模，不能把临时批量选择误当追踪事实。关闭后侧栏“已上图”状态同步，原批量选择按稳定ID保留。

### C. 勾选即生效与历史

1. 全览勾选：向当前画布添加对应流水；取消：从当前画布移除对应流水。其含义在列名/轻提示中明确，已有上图项初始即勾选。关闭视图不等于取消。
2. 反选仅移除对应流水，不清空其他已上图事实；移除与添加均可撤销。表头全选默认作用当前页，明确写出范围；不暗中全选整个查询库。
3. 每行区分期望状态、进行中和服务器确认状态；保留一个权威追踪集合。快速勾选/反选按最新意图串行收敛，不能因现有history busy保护而吞掉后续点击。
4. 复用case/canvas-bound CAS与历史命令；批量动作合理合并为可理解的一步，禁止每个UI属性变化都建立历史。历史仍有40步/8MiB边界，不保存交易事实或照片。
5. 行内“添加中/已上图/移除中/失败”反馈明确；失败回退对应行至已确认状态并允许重试，不覆盖其他成功操作。回执不明时沿用fail-closed，不能伪装成功。
6. 关闭全览时，已经发送的操作在原绑定中完成，不出现额外“确定”；未发出的队列要有明确收敛策略。切案件/画布立即撤销旧界面和旧回调的发布资格，覆盖A-B-A及延迟响应。
7. 开关全览、折叠查询、移动焦点、查看详情、分页等浏览操作不记图谱历史。新选择可以添加节点，但不能每次都重置已有节点位置、相机或自动缩放；使用现有渲染与布局边界验证这一点，不改G6算法。

## 7. 验收矩阵与停止条件

- 既有合成unit/API/history/case-isolation和新增公共行为回归；保持Decimal金额、案件隔离、CAS、导入完整性、桌面请求认证/CSP不退化。
- 重点组合：调宽→收起→缩窗→展开；查询展开/收起与左右面板独立组合；全览中连续勾选/快速反选/全选/撤销/失败/关闭/切案/切画布；弹层内焦点遇resize/scroll/外点/Escape。
- 视口以常见桌面1366×768、1440×900、1920×1080加960×640及小窗口599px为代表，补100%/125%/150%浏览器缩放。不要把CDP pinch或CSS缩放冒称浏览器缩放/Windows DPI。
- 同视口比对展开、紧凑、查询收起、全览、空/加载/失败/选中/禁用状态；触屏与减少动态效果按实际环境区分模拟和实机。
- 数据与隐私：仅合成临时数据，账户/金额完整，不外传本地业务内容；关闭全览和折叠不清除追踪事实。图谱在外围布局变化前后按节点ID比较位置和相机矩阵。
