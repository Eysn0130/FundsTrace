## 2026-11-10：三层工作区与本机参考尺寸

深色外壳使用系统顶栏／导航 `#333333`、工具与查询／表格 `#222222`、画布／空画布 `#181818`。浅色与重点色沿用既有设置，业务角色及保存的绘图颜色独立。Retina 2 倍截图落实为逻辑尺寸：顶栏 44px、导航 52px、选中块 36×36px、右底边 4px、内圆角 12px；Logo 24px，选中块 8px 圆角、重点色实心底和白图标。[测量记录](media/three-zone-workspace/reference-measurements.json)保留原图像／逻辑像素口径。

`常用／追踪分析／图形样式／视图` 四页签复用原命令，一次只开一个面板。展开时大按钮图标在上、文字在下，宽窗保留底部分组标题并局部横滚；图标 24px／文字 12px，窄槽图标 22px。面板宽／窄高 92／72px；含上下文行的展开区宽／中／堆叠高 137／117／145px，折叠高 87／87／115px。旧 148／66px 尺寸已被替代。

缩略图占位 136×113px，绘图区 131×80px，地图卡片 136×85px、胶囊 136×23px、间距 5px；沿用位图与指针坐标换算。图例整体缩为原来的 50%，小画布中两者独立避让。左侧概括行和来源覆盖整段不显示，内部统计／审计绑定保留；导航底部更新控件仅在有真实更新状态时占位，设置中的手动检查保留。节点名称准入与全图测量以图谱渲染专题为准。

## 操作区与折叠

- 案件、画布及具名导入／分析／导出／管理入口保留。清空图谱有独立确认，删除案件／画布仍在其管理入口。查询、侧栏和顶部工具独立折叠；hover／focus 只露切换 seam，点击才改状态，触屏命中区至少 44px。
- 紧凑区仍可保存、撤销／重做、布局、适应和使用金额／时间；低频显示项复用原控件的弹层，不复制 ID 或业务绑定。侧栏可拖动／键盘调宽，宽度偏好与当前可用界限分开，折叠不清查询、选择、位置或画布。
- 查询草稿与已提交结果意图分开。续载及权威刷新沿当前有效查询的冻结条件、目标页与位置，不悄悄提交草稿或退回更早成功查询；失败结算后保留上次有效结果。切案／画布撤销该绑定的旧意图。
- 过渡约 220ms，可中断反向；减少动态效果时取消空间动画。容器变化不重布局、不重建 G6；窗口、工具和手动调宽只补偿原点，显式折叠使用下述相机策略。金额、账号保持完整，窄窗只在表格局部横滚。

## 共享流水全览与两种选择

- 全览移动同一组表格、工具与提示 DOM，不复制数据或事件。侧栏复选框为批量追踪锚点，全览第一列“上图”为当前画布成员；两种选择独立，关闭全览恢复锚点，刷新／续载保留锚点，表头全选只覆盖当时已载入窗口。两视图分别保存页面内滚动位置，表头固定。
- 全览勾选即时上／移图，权威追踪集合为确认状态，行内保留期望、pending 和失败。快速反选串行收敛到最新意图；明确失败只回退对应操作。已有位置和通常相机保留，新增端点在屏外时才适应；邻域只纳入此次明确上图端点，不带回其他隐藏节点，撤销恢复原视图／相机。
- 关闭、Escape 或真正外遮罩关闭全览，不取消同绑定已发送／排队动作；表格及滚动条拖动不是遮罩点击。切绑定取消未发送意图，已发送写入在原绑定结算，旧回调失去发布资格。切换立即清旧 DOM、计数、续载、锚点及全览，首次成功读图后重查一次，序号／代次覆盖乱序及 A–B–A。
- 重建行前保存稳定 ID、焦点和位置，重建后恢复同控件；目标消失回同行或表格区，不抢表格外焦点。单击选行／定位，双击或 Enter 详情，成员操作与锚点独立；画布 Ctrl／⌘A、Delete／Backspace、Ctrl／⌘Z 沿原绑定写入与历史边界。

## 渲染冻结与模块边界

工作区模块只拥有各自状态，不新增第二套图事实或相机所有者。外壳改变不顺带重写节点／边渲染；渲染修改须有自身需求与验证。

| 模块 | 职责 |
| --- | --- |
| `workspace-shell.js`／`ribbon.js`／`ribbon-commands.js` | 外围布局、折叠和宽度；Tab、单实例控件槽、弹层／键盘；复用既有编辑命令。 |
| `workspace-camera.js` | 原点补偿、显式侧栏构图、快速反向、导出暂停及历史仿射补偿，不改节点世界坐标。 |
| `table-workspace.js` | 查询草稿／冻结意图、序列、全览、两种选择展示、焦点／滚动及绑定重查。 |
| `canvas-editor.js`／`canvas-history.js` | 原子 membership 的 set／snapshot／subscribe、串行确认／失败；有界绑定内历史和成功后移动指针，不复制渲染。 |
| `ui-dialogs.js`／`workflow-ui.js` | 模态 inert、层级、Tab／Escape／还焦、遮罩／IME／裁剪键盘；导入会话与只读进度恢复、明细失效及反馈。 |
| `graph-relations.js`／`graph-presentation.js` | 金额条件、线宽与白名单样式等纯展示策略。 |

### 现有入口与包装次序

[index.html](../static/index.html) 的相对加载链为 [app.js](../static/app.js) → [canvas-history.js](../static/canvas-history.js) → [canvas-editor.js](../static/canvas-editor.js) → [table-workspace.js](../static/table-workspace.js) → [workspace-session.js](../static/workspace-session.js)。后加载包装在外层，装载次序与调用次序分别核对。

`loadGraph` 最终签名为 `async (retry = true, context = caseContext(), { tableQuery = 'binding' } = {})`，向内调用 table-workspace → canvas-editor → app；workspace-session 不包装它。表格先失效选择，editor 等待同案同画布旧 generation 已发送写入结算并复查绑定，app 按绑定及序号发布图。返回时 editor 仅向当前绑定发布 membership；表格再核对 refreshBinding／当前绑定／图就绪，清标记并重查一次。`tableQuery: 'caller'` 由恢复条件的调用方独占最终查询。返回仍是原 `Promise<void>`；完成或早退不是耐久写成功回执。

`selectCase(caseId)`／`activateCanvas(id)` 的包装保持同步：workspace-session 先 `capture()`，table-workspace 再 `invalidate()`，editor 调 app 原函数切换绑定后重置手势／membership／history，表格登记新 refreshBinding，最外层最后 `resetQuery()`。各层保留原 this、参数和返回值；capture 必须早于清表和选择，不能按加载次序倒置。

`refreshAll` 固定完整案件／画布绑定、跨异步边界复查，读图用 caller 查询所有权。普通返回刷新有效已提交条件；账户“查看流水”透传 caller，由显式目标账户独占查表，统计／图／批次照常刷新。身份写入若已返回主页再刷新表格，否则交之后的返回动作；照片修改不额外触发此身份查询。未完成查询保留冻结条件、摘要、目标页和位置，旧回调只能清自己的记录。

改接缝时联查相邻包装、源码抽取点及 `tests/workspace_session_harness.mjs` 的账户命令／导航／图／表组合回归。保留 A–B–A、旧写结算后再读、迟到拒绝和单次重查；合成 DOM／G6／响应不能替代候选实际浏览器流程。

## 工作区视图

同一查询、七列表格和图谱有三个区域预设，详情抽屉独立：标准每次展开工具和查询；专业每次收起两者但保留上下文／快捷带，Tab 可临时展开，内部 `focus` 标识兼容；上下分栏画布在上、原表格在下，首次收筛选，分隔线支持拖动／方向键（Shift 50px），尺寸变化重算高度，通常保留至少 140px 图谱，极小窗口按实空间夹取。

标准／专业重复选择也恢复预设，手动调整不覆盖预设；上下分栏记自己的区域状态。各视图保存筛选展开与表格滚动，切案／画布清旧位置／锚点；底部高度和模式不新增持久键，侧栏宽度沿旧偏好。分栏自动列宽按内容分配、完整金额与锚点保留，手动宽度可恢复自动，迟到测量不覆盖别的视图位置。切视图只改外壳，不请求布局／适应、不写成员或历史；全览关闭回原槽，分栏复选框仍是锚点。

## 画布撤销／重做

上图、批量追踪、移除、清空、布局、显示、邻域及几何编辑可入历史，一次批量一步；自动初始布局、平移缩放和纯浏览不记。Ctrl／⌘Z 撤销，Shift+Z 或 Ctrl+Y 重做，输入与对话框保留原生键盘。历史仅 ID 集合、几何、相机及显示设置，不存交易事实／金额／照片，最多 40 步、估算 8 MiB，超限提示并修剪，刷新／切绑定（含 A–B–A）清空。

membership 与布局／历史共用串行边界，未发送中间意图可合并；多次实际写入的快速反选可能有多步。`PUT /api/track/state` 在案件／画布事务内以 expected_ids 比较后恢复 desired_ids，409 不覆盖并发；批量 API 的可选 expected_ids／完整 tracked_ids 保留旧调用兼容。写后刷新失败按实际写后集合比较补偿；回执丢失或补偿冲突时撤销旧图事实／历史并提示重载，不能报告 undo 成功。导入、源流水／案件删除、身份／照片及案级主账号不属于此历史，没有持久历史或通用数据库回滚框架。

## 显示与导出

金额条件以已上图关系的精确 amount_totals 按所选币种比较，含等号；币种缺失独立处理，非法／反向区间保留原视图。线宽仅将有界比例转数值，统一映射 1.5–7px 的平方根几何；缺币种用普通线宽且说明，不回退笔数，编码开启禁固定线宽。筛选边集合独立，不因两端可见带回筛选外边。

显示条件及白名单样式入画布／历史，旧无 presentation 和绝对标签快照兼容；恢复样式不清交易、位置、业务角色、筛选或金额编码。多选逐属性呈共同／混合值，单边样式不覆盖其他边。绘制、控件、测量与 HTML 共用有效字体／行高／底板，旧字号的行高不低于字号加 4。手动标签保留 labelRatio／labelManual，隐藏边不伪造绝对点，自动避让不升级为手动。照片保存为当前案件引用，旧 img 不复活已清照片；不批量删除旧嵌图，独立 HTML 可嵌导出时当前照片。

保存／另存始终保留完整图；HTML 保留当前显示／邻域和标签可见性，PNG／PDF 在当前显示范围使用全部标签，Excel 取完整追踪集合，案件包取案内关联资料。导出说明筛选、币种、线宽及可见／全图计数，临时选择装饰只在同绑定内恢复，失败／取消／换绑不污染新图。独立分析页只跑明确选中算法，HTML 报告沿最近成功案件／参数；下载生成与用户实际落盘分别记录。

## 导入、明细与导出契约

导入窗口按案件绑定管理上传、预览、重识别、提交和轮询；关闭已提交任务只隐藏，同页面同案重开恢复进行／待确认状态。 多文件队列关闭或切换案件会停止后续未启动文件；已提交任务按原回执结算，未上传文件需重新选择，已上传任务可从本案导入记录恢复。回执丢失或读取失败时只查询已知 import ID，不重放提交，明确失败后才允许手动重试；窗口恢复不承诺刷新／重启自动重建。持久任务恢复另按[导入生命周期](import-lifecycle.md)。

详情／上下文由当前案件／画布及请求令牌保护，晚响应不重开已关抽屉；上下文上图未完成保留选择与反馈。画布管理用 `canvas-workspace.js` 的绑定写锁，未知写入先只读核对、不按名称猜成功或自动重试。默认画布改名／删除由前后端拒绝，删除不删源流水和其他画布；案件包预保存共用锁，默认画布另存后仍保持当前画布。新建／另存／删除提交时不能关闭确认表单，避免后续草稿被迟到切换覆盖。

## 顶栏二级菜单组件（图 4）

`toolbar-menu.js` 提供 open／close／isOpen／getState／place：按钮 data-toolbar-menu 指向 body 级 role=menu 面板，行用 menuitem、不可用用 aria-disabled 并保留聚焦，表单仍为 dialog。已有 Tabler SVG 和 --menu-* token 统一外观；仅 Escape 主动还焦。菜单不碰图事实／相机／历史，第一次图谱外点完整手势由菜单消费，其他顶栏按钮可直接交接；resize、scroll、锚点隐藏／移位关闭。图标许可见[第三方通知](../THIRD_PARTY_NOTICES.md)。

## 镜头与缩略图

显式收起查询区时，完整可见图按新增宽度适度放大／居中，受实际内容、24px 留白、覆盖层及 G6 最大缩放约束；右侧已有越界内容则保比例平移揭示，世界坐标不变。沿 ResizeObserver 实际几何进度同步，未受干预展开反向恢复基线，快速反向不重置。手动相机、布局或换绑定结束自动构图；导出暂借相机、恢复后消费暂停进度，历史／失败补偿沿累计仿射变换。

固定 G6 4.8.19 的 changeSize 清位图而 paint 排下一 rAF，适配层因此仅对当前未导出 Canvas 以版本／方法守卫同步 `_clearFrame()`／`_drawAll()`。这是锁定渲染器接缝；更换版本须重核连续帧及[固定补丁](../static/vendor/G6-PATCH.md)。

缩略图沿当前相机提供定位、相对拖动、方向键、缩放、100% 和返回显示范围，不改事实／筛选。主题、重点色、透明材质沿统一设置，仅展开偏好存 fund_minimap_expanded。尺寸沿上面的现行半尺寸；窗口变化只改视窗框，高度不足先收地图，完整胶囊也放不下则隐藏导航层并撤销交互，空间恢复回原偏好，不写展开设置或自动适应。

开合完整行程 220／160ms，以透明度、8px 位移和轻微缩放从当前帧反向；减少动画时直接落定，收起立即撤导航及焦点。点击松手确认，移动小于 4 CSS px 按点击，280ms cubic ease-out 平移到实际中心且保倍率；超阈值直接拖动并保按下偏移。14px 目标环只作装饰。连续点击转最新目标，手动相机、尺寸、导出、忙态及换绑终止旧运动；绘制前同步裁剪，防远距离移动沿用旧帧造成途中缺图。
