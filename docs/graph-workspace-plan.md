# 石墨色图谱编辑工作区

状态：已确认设计的源码候选，2026-10-15。左侧、顶部工具带与查询表单可以独立折叠；流水全览使用即时上图语义。源码、浏览器与安装包证据分别记录；本轮不改变已发布 v0.1.0 安装包。具体操作见 [工作台使用指南](workspace-guide.md)，本轮执行范围见 [最终版 UI 施工计划](release-ui-plan.md)。

## 操作区与折叠

- 案件栏保留品牌、案件上下文及导入、分析、导出入口。完整编辑工具带按画布文件、编辑、布局、显示、主账号与清理分组，恢复日常直接操作；清空当前图谱保留独立按钮和确认，删除案件／画布仍在具名管理入口。
- 左侧与画布交界垂直中点、工具带下沿水平中点提供切换按钮。悬停对应区域或边缘、键盘聚焦时显示，离开淡出；点击才改变展开状态。触屏保留可见且至少44px的命中区。
- 左侧收起后保留边缘感应带；顶部收为紧凑工具区，保存、撤销、重做、布局、重新布局、适应画布及金额／时间仍直接可用。低频显示项使用同一组原控件的弹层，不复制控件和业务绑定。
- 三处独立展开／收起；查询表单收起后保留条件摘要、结果数、表格工具、批量追踪与全览入口。未提交的筛选显示当前草稿及“待查询”，与上次结果数区分。
- 左侧可拖动或用方向键调宽；折叠不清查询、勾选和画布状态。用户宽度偏好与可用空间上限分离：resize和展开均重算边界，599px视口可保留200px画布，宽屏恢复本次页面内的宽度偏好。更小窗口保留可达的画布边缘。过渡约220ms，可中断反向；减少动态效果时取消空间动画。容器变化沿用既有尺寸观察，不触发重布局、自动适应或G6实例重建。
- 流水保留勾选、交易时间、付款方、收款方、金额、摘要、操作七个真实表格列。金额与账号完整，长文本换行或完整单行；列宽不足仅表格局部横滚。宽栏紧凑排布，窄栏保持控件可达，不能以裁断金额或无限缩小字号换取空间。
- 图例与缩略图仅调整外围样式及定位，沿用原缩略图交互。

## 共享流水全览与两种选择

- 表格工具区扩大图标打开居中模态全览。移动同一组表格、工具、提示、横滚和分页节点，避免复制数据、控件ID或事件绑定。两种视图分别保存本次页面内的滚动位置；七列表头固定、内容独立滚动，窄窗继续局部横滚。
- 侧栏复选框选择批量追踪的“锚点”；全览第一列明确标为“上图”，复选框表示当前画布的追踪成员。两种选择独立维护；关闭全览恢复侧栏锚点，普通结果刷新与翻页保留锚点。两种表头全选均明确限定为本页。
- 全览勾选／取消即时添加／移除该笔流水。以权威追踪集合为确认状态，行内展示期望状态、pending和失败。快速反选按最新意图串行收敛；明确失败仅回退对应操作并允许重试。已有节点位置和相机保留，不为每次勾选触发适应画布。
- 关闭按钮、Escape或真正外部遮罩关闭全览，无确认／退出页脚。关闭不取消当前绑定中已经发送或排队的操作；表格或滚动条的内外拖动不作为遮罩点击。切案／切画布撤销旧绑定，未发送意图取消，已发送操作留在原绑定中完成，旧回调失去发布资格。
- case/canvas切换立即清空旧流水DOM、计数、页码、锚点及全览；目标图首次加载成功后重查一次。查询响应使用请求序号和绑定代次检查，覆盖乱序及A–B–A。失败保留上次有效结果并明确提示。
- 行数据重建前保存稳定流水ID及当前控件，重建后恢复同一控件焦点与滚动位置；行或操作消失时回到同行或表格区域。表格外焦点不被抢走。

## 渲染冻结与模块边界

本轮保留 `static/app.js`、`static/graph-*.js` 和锁定的G6文件。节点、节点关系、边线、标签、布局算法与图形交互源码不变。

| 模块 | 职责 |
| --- | --- |
| `workspace-shell.js` | 外围布局、侧栏／工具带折叠、宽度偏好与实际边界、紧凑弹层及自动关闭后的焦点返回 |
| `table-workspace.js` | 查询独立折叠、草稿与结果摘要、查询序列、共享全览、锚点与上图选择展示、表格焦点／滚动恢复、绑定失效后的表格重查 |
| `canvas-editor.js` | 在既有命令边界适配历史和原子追踪集合；membership adapter提供`set / snapshot / subscribe`，串行收敛最新意图并发布确认、待处理和失败状态；不复制图形渲染 |
| `canvas-history.js` | 有界内存历史、串行命令、成功后移动指针与绑定清空 |
| `ui-dialogs.js` | 模态背景inert、嵌套层级、Tab／Escape／还焦、真正遮罩手势、命名输入IME边界、推荐项与裁剪区域键盘操作、映射标签绑定 |
| `workflow-ui.js` | 导入窗口会话与只读进度恢复、明细请求失效保护、详情抽屉操作反馈及焦点恢复；继续调用既有服务和渲染 |

局部图标取自本地锁定的Tabler Icons，许可见 [第三方通知](../THIRD_PARTY_NOTICES.md)。分析页保留独立脚本，向既有算法服务提交明确选中的算法和参数；本轮不新增分析算法。

## 画布撤销／重做

- 支持上图、上下文上图、批量追踪、移除、清空当前画布、布局、显示设置、邻域及几何编辑。一次批量动作记一步；初始自动布局和单纯平移缩放不记历史。
- 按钮提示下一步动作；Ctrl/Cmd+Z撤销，Shift+Z或Ctrl+Y重做。输入框、可编辑内容及打开的对话框保留原生键盘行为。
- 历史仅含流水ID集合、几何、相机矩阵和显示设置，不保存流水事实、金额、证件或照片。默认最多40步、8MiB估算存储；超出容量明确提示并修剪。刷新、切案、切画布（包括A–B–A）清空历史。
- 操作串行；恢复成功才移动历史指针。`PUT /api/track/state` 在案件／画布事务内比较 `expected_ids` 并恢复 `desired_ids`，冲突409且不覆盖并发操作。批量API可选 `expected_ids` 并返回完整 `tracked_ids`，供写后失败补偿；旧调用仍兼容。
- membership与布局、撤销等命令共用串行边界。尚未发送的中间意图可以合并；每次实际提交的批量动作记为一步，已形成多次写入的快速反选可能有多步历史。开关全览、查询折叠与其他纯浏览操作不记历史。
- 成功写入后刷新失败，使用实际写后集合做比较后补偿。回执丢失、补偿冲突等无法确认状态时撤销旧图事实与历史并提示重载，不冒称恢复成功。
- 原始流水、导入、案件／画布删除、身份／照片资料和案件级主账号修改不属于此历史。没有持久化历史表或通用数据库回滚框架。

## 导入、明细与导出契约

导入以案件绑定的窗口会话管理上传预览、重新识别、提交及进度轮询。关闭已提交任务只隐藏窗口，同一页面同一案件内重新打开恢复进行中／待确认任务。提交回执丢失或进度读取失败时，“重新读取进度”只查询已知import ID，不重放提交；明确失败后才允许用户检查并手动重试。此窗口恢复不承诺刷新或重启后自动重建。

详情抽屉和流水上下文使用当前案件／画布和请求令牌保护；晚响应不重新打开已经关闭的详情。明确失败显示重载／重试入口；上下文上图未完成时保留勾选和反馈，不同步关闭窗口。

图谱PNG／HTML／PDF按当前图谱视图导出，邻域状态仅包含当前邻域；画布保存使用完整图快照。追踪Excel取当前案件／画布的完整追踪集合；案件包取当前案件及其关联资料。独立分析页只运行选中的算法，HTML报告沿用最近成功分析的案件和参数。下载生成成功与用户保存落盘分别记录。

## 验收边界

本轮以合成临时数据检查用户流程、状态机与事务失败／并发边界。当前候选的浏览器截图、视口、实际交互和定向检查范围以 [design-qa.md](../design-qa.md) 及 [最终版 UI 施工计划](release-ui-plan.md) 的对应记录为准；第一轮截图或旧passed不自动代表新候选验收。生成设计图中的示意流水及统计数不能作为业务期望值；完整金额、当前案件绑定与实际G6渲染优先。

桌面静态资源清单包含新增脚本和本地图标；资源边界检查不等于重新打包。Windows原生GUI／安装、DPI、真实浏览器缩放及触屏实机验收尚未执行（NOT_EXECUTED），浏览器视口与媒体模拟不替代上述证据。本轮交付为源码候选，不以历史发布运行替代新候选证据，也不改变已发布v0.1.0二进制。
