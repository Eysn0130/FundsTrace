# 高密度流水表格：交互、研究与验收

本次沿用真实七列表格，默认增加“两行概览”。维护者选择的交互是：**单击选行／定位，独立按钮上图或移出，双击或 Enter 查看详情**。左侧复选框继续表示批量追踪锚点；它与当前行、画布成员分别表达不同状态。

## 研究取舍

| 成熟方案的一手资料 | 本次采用的原则 |
| --- | --- |
| [TanStack Table](https://github.com/TanStack/table) 的[列宽](https://tanstack.com/table/latest/docs/framework/react/guide/column-sizing)和[行选择](https://tanstack.com/table/v8/docs/guide/row-selection) | 列宽有独立状态及上下限；选择状态不依赖当前渲染行的位置。 |
| [AG Grid](https://github.com/ag-grid/ag-grid) 的[完整值提示](https://www.ag-grid.com/javascript-data-grid/tooltips/)及[多行选择](https://www.ag-grid.com/javascript-data-grid/row-selection-multi-row/) | 只为被截断的内容显示完整值，并允许进入浮层操作；复选框与单击选择可以独立设置。 |
| [MUI X](https://github.com/mui/mui-x) 的[列尺寸](https://mui.com/x/react-data-grid/column-dimensions/)及[行选择](https://mui.com/x/react-data-grid/row-selection/) | 最小列宽、拖动和内容适配各有明确边界；交互单元格不应连带触发行选择。 |

这些原则适配现有 G6 工作台，未引入表格依赖、复制库代码或迁移前端。整行单击上图会与双击详情的第一次 click 冲突，也容易把浏览行为变为写入，因此使用维护者确认的独立操作。

## 最终行为

| 操作 | 左侧表格 | 流水全览 |
| --- | --- | --- |
| 单击普通单元格 | 选中当前行；端点已在当前显示图中时定位，不自动上图 | 只选行，不平移被对话框遮住的画布 |
| 双击普通单元格／行上 Enter | 打开既有前后流水详情 | 同左 |
| 第一列复选框／行上空格 | 选为批量追踪锚点 | 即时改变当前画布成员，沿用原全览契约 |
| 行内上图／移出 | 显式改变画布成员，可撤销，原始流水保留 | 使用第一列成员复选框；不重复显示行内上图按钮 |
| 拖动表头分隔线 | 调整该列宽度 | 独立保存全览的列宽 |

普通行底色表示服务端已确认的上图状态；部分来源观察已上图时使用较浅底色和“部分·移出”。当前行另有边线，批量锚点另有勾选。处理中禁用对应行按钮；失败不把整行伪装为上图成功。按钮、复选框、选择文字和列宽手柄不触发普通行定位／详情。

### 两行概览与完整值

- 户名一行、账号一行，过长分别显示省略号。时间分日期／时刻两行，摘要最多两行。完整字符串保留在 DOM 和原始数据中；摘要、账号和时间的截断不进入查询、详情、持久化或导出。
- 溢出内容悬停约 300ms 打开完整值浮层，可进入浮层选字，或点“复制完整值”。鼠标离开后有短暂关闭延迟；Escape 先关闭该浮层，全览保持打开。复制只在显式按钮操作后发生；失败时允许选字复制。
- 金额保留完整币种、位数和小数，不用省略号；实际金额文本宽度成为金额列的动态下限。来源记账说明保留，复杂来源内容可能使行高超过两行，不能为固定高度掩盖金额或来源性质。
- 紧凑合成样本行高 44px；舒展模式实测约 61.39px。保留“完整换行／完整单行”供深入核对，仍使用局部横滚。旧的文本模式草稿继续生效，默认模式不强行覆盖已有偏好。

### 列宽和连续浏览

| 列 | 最小宽度（CSS px） |
| --- | ---: |
| 锚点／全览成员 | 40／96，固定 |
| 交易时间 | 88 |
| 付款方、收款方、摘要、操作 | 各 112 |
| 金额 | 112 与完整金额实际宽度中的较大值 |

其余六列表头支持鼠标拖动、方向键 8px／Shift+方向键 1px、Home 到下限、双击按**当前已加载内容**适配；不为自动列宽读取全案。Escape 或指针取消恢复拖动前宽度。“恢复自动列宽”清除当前视图的手动宽度。侧栏／上下分栏／全览、行距和文本模式各自保存宽度偏好，存储只有七个宽度数值，不含账号、流水 ID 或正文。

两行概览在上下分栏／全览中按已加载内容和实际字体测量自动列宽：时间、完整金额及操作列取合适宽度，付款方／收款方采用对称的内容需求，摘要按两行需求测量。三列文字的首选宽度保持均衡，再共同分配剩余空间，避免摘要独占空白；标准侧栏继续使用紧凑配置，固定列下限同样按实际内容校正。数字字体的 CSS `font` 简写为空时，使用实际字体各部分测量。

窗口伸缩和结果刷新后重新分配，当前查询只保留两档行距的七个数值包络，不留存额外账号或正文。已展开的文字列不会在调整另一列时突然被侧栏上限压缩。使用手动列宽时继续尊重已设置的值，可恢复自动重新适配；空间不足时保留七列最小宽度及局部横滚。

连续读取仍沿用原来的 50 行分页、最多五页窗口及案件绑定；列宽包络只保留有限数字，不留存被回收的行。完整换行／单行模式继续保留宽行离开窗口后的列宽，避免横滚突然回零。切换模式保留可见行锚点，旧侧栏的延迟测量不能把横滚位置写进全览。底部 18px 水平控件继续常驻，七列均已容纳时禁用。

## 实际合成浏览器验收

输入为确定性的七节点／六笔 hub，使用长户名、24 个零前缀的账号和重复五次的摘要，含 `¥9,999,999,999,999,999.99`、`¥0.01` 和 `USD 0.20`。输入规则见 [table-fixture.json](media/three-zone-workspace/table-fixture.json)，观察值见 [dense-table-verification.json](media/three-zone-workspace/dense-table-verification.json)。未使用维护者截图中的真实大案件或原件。

1. **读表密度。** [修改前](media/three-zone-workspace/table-02-long-before.png)完整换行下每行约 344.72px；[两行概览](media/three-zone-workspace/table-03-two-line.png)为 44px。双方 CSS 视口均为 853×1155；前图 IAB 82% 浏览器缩放、700×947 捕获像素，后图 Chrome DPR 1、853×1155 捕获像素。没有把截图像素当作列宽，也不声称背景或相机逐像素一致。
2. **查看完整值和选择。** [完整值浮层](media/three-zone-workspace/table-04-full-value.png)展示未截断的户名及零前缀账号。实际单击选中行后，追踪仍为 6 笔、历史为 0；显式移出后为 5 笔，原结果仍 6 行；画布撤销恢复 6 笔。双击打开对应字符串 ID 的既有详情；该观察不替代详情中全部分析功能验收。复制按钮的精确文本写入由合成剪贴板回归验证，未读取或覆盖用户剪贴板。
3. **调宽与恢复。** Chrome 实际鼠标拖动付款方列 112→160px，重载仍为 160px，恢复自动后为 140px。列宽控制焦点上的 Ctrl+Z 不误撤销画布。取消拖动、键盘微调、侧栏／全览隔离及迟到模式回调另有行为回归。
4. **全览和退出。** [1512×949 全览](media/three-zone-workspace/table-06-overview.png)保留一张原表、七列表头、六行及完整金额。最后一列手柄越界导致的额外 3px 横滚已修正，最终 scrollWidth/clientWidth 均为 1396，底部控件禁用。实际全览内完整摘要浮层可聚焦，Escape 只关闭浮层并回到行；切案后旧完整值立即清空。

检查发现并修复了两行摘要在舒展行距中被固定高度裁掉、金额最小宽度不足、旧文本模式横滚位置被清零、最后手柄制造空白横滚、全览浮层在模态之外被设为 inert，以及行 ID 转为 Number 的精度风险。案件切换、控件焦点、部分成员与失败状态沿用现有受绑定保护的查询和画布写入。

### 可访问性与证据限制

六个列宽手柄可键盘聚焦，具备分隔线名称和当前／最小／最大宽度；复选框触点至少 24px，保留行焦点与上下键浏览。完整值可选择并提供复制按钮，Escape 不连带关闭父全览。普通截断单元格的完整浮层目前以指针悬停为入口，键盘用户可使用 Enter 详情或完整文本模式；未作屏幕阅读器或触屏端到端验收。

合并主分支前，本轮定向回归 **14 passed**，其中 table wrapper 执行 59 个 Node 行为用例，不能与包装测试相加。随后接入 main `7388575` 的查询生命周期和卡号显示改动，仅有表格测试新增位置冲突，两组测试均保留。合并后原定向集合加账户／关系工作区及卡号显示查询公共回归为 **27 passed in 60.05s**。覆盖案件／画布切换、精确字符串 ID、逐行与聚合来源成员、失败恢复、窗口回收、滚动与焦点、列宽和完整值。
