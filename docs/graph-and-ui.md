# 图谱与界面交付

本文保留上一轮金额、按钮与 Worker 布局的交付证据。后续标签分级、邻域展开及页面交互测量见 [图谱交互](graph-interaction.md)；当前预览参数会创建恰好指定数量的图账户，下面的 1004 个账户属于旧版 fixture 记录。

本轮沿用 Frontend Skill 的应用工作台规范：清晰操作层级、可读密度、已有配色和克制动效。UI/UX Pro Max、Taste、Impeccable 的参考研究见 `docs/frontend-host-adaptation.md`，没有安装远程脚本或新增组件库。没有增加 Electron 壳，也没有修改 Analytix。

按钮变形已在 1280px 实际浏览器复现：固定 50px 顶栏挤入过多操作，部分按钮缩到 30px 宽、105px 高，文字竖排并覆盖主区。现改为顶栏自然高度、容器换行、按钮单行且不压缩。图例/图谱工具栏/画布各占独立区域，ResizeObserver 按真实画布尺寸更新 G6。窄窗查询与图谱上下排列，表格在内部横向滚动。闭合抽屉不再移到页面外制造横向溢出；抽屉淡入尊重减少动效偏好。React 的标题操作、弹窗底部、历史记录、来源分页均允许换行，模式选择不再强制 240px 最小宽度。

保留本地 G6 4.8.19 引擎。原同步布局每次执行 120/240 轮逐对斥力，阻塞页面主线程。新独立 Worker 计算有界网格近似几何，批量落位后绘制一次；账户金额不进入近似布局。首次空图上图触发布局，已保存位置保持不动；确定性初始坐标减少刷新抖动。案件/画布切换、节点拖动和新布局会取消过期计算。无 Worker 时小图分步让出事件循环，大图退回线性层次排布。平移/缩放启用本地 G6 内置交互优化，结束后恢复标签；不添加持续节点动画。

图谱 HTML 导出现在同时保存精确金额结构与可见标签，照片读取期间如果案件/画布发生变化便取消，避免把旧案内容冠上新案名称。新建案件复用页面弹窗，避免浏览器原生 prompt 的宿主兼容问题。

可重复的布局基准：

```sh
node tests/graph_layout_benchmark.mjs 1000
.venv/bin/python scripts/preview_synthetic.py --graph-nodes 1000
```

第一个入口为固定种子的 1000 节点/999 边合成链图，内置改造前 FR 作为对照。两个内核使用同一 Node/V8 原生 realm；候选放在独立 worker_threads 中，避免给单方加入 VM 沙箱开销。第二个入口创建可随时删除的临时数据库、合成授权与文件，默认基础 4 个账户加链图 1000 个账户，共 1004 个账户，不连接原目录。

本机 Node 22.22.1，3 次独立进程观测（同一内核 SHA-256 `1bdcac77ab46ed9bdb24966b700b2a6075ebce94b660c6a2c92ffc0ce1fe7491`）：

| 指标 | 三次观测 | 中位数 |
| --- | --- | --- |
| 原同步内核 | 244.15 / 199.24 / 206.49 ms | 206.49 ms |
| 新 Worker 内核 | 176.89 / 183.94 / 185.27 ms | 183.94 ms |
| Worker 总耗时（含启动/传输） | 194.71 / 203.76 / 205.22 ms | 203.76 ms |
| 主线程 10ms 心跳的最大观测间隔 | 11.11 / 11.13 / 11.09 ms | 11.11 ms |

改进重点是计算移出主线程；不能把内核耗时改善等同于页面首绘改善。算法改变了几何分布，力计算次数也不直接可比。样本量 3，不提供稳定尾延迟、60FPS、真实案件或发行性能保证。原始合成 JSON 在 `output/benchmarks/graph-layout-1000-samples.json`；不覆盖此前数据库性能历史基线。

实际浏览器已验证：1004 账户布局完成、空案切换后返回、最大金额按分筛选；1280px 顶栏按钮完整、G6 平移/缩放结束标签恢复；390px React/旧 G6 无整页横向溢出、导入预览按钮保形；分析路径及图谱通过界面下载后回读金额与标签。截图和回读 JSON 在 `output/money-ui/`，仅含合成数据。

最终验证：Python 231 项通过（其中旧前端 wrapper 执行 23 个 Node 行为子测试）；React 37 项通过，TypeScript/Vite 构建通过；生成 v1 契约无漂移；100 行三次隔离合成基准的完整性检查通过，计时不用于性能结论。三份 CSS 经 Lightning CSS 严格解析。原目录 6040 个文件的路径/大小/修改时间快照相同，仅检查元数据、没有读取业务内容。

本轮之后，按缩放分级的标签、分批邻域和首绘／交互采样已落地，见 [图谱交互](graph-interaction.md)。聚合等后续工作仍需以同一合成图集比较。千节点同时显示完整账户与金额仍然拥挤，动画无法解决信息密度；以测量结果判断图引擎或 Rust 是否确有必要，并保留 React 共享面板与宿主接口边界。
