## 数据与校验

CSV 有 21 列，包含中文、8 个额外宽字段、可空银行/余额/币种/摘要、日期斜线与货币符号格式、前导零账号、256 个对手账户、收支方向。每 100 行有 1 行无效日期和 1 行无效金额，每 10 行的第 10 行重复前一行。另有 1 笔 `9007199254740991.13` 的大金额哨兵，用来检出金额经 binary64 中转丢失分的问题。

预期行数、去重数、金额与方向由生成规则的整数运算单独计算，不从 `build_rows` 或查询结果反推。读取原始 DuckDB `Decimal` 校验精确总额，再逐行以独立 SQL 核对金额分、时间、对手账号、方向、来源编号与缺失余额。主案件重复导入不得新增流水，同样的 3 笔流水在另一案件仍应独立入库。注入“已插入后回调失败”校验流水与批次同时回滚。JSON 中大整数金额分以十进制字符串保存，聚合对象另附 SHA-256。

图谱调用现有 `main.graph`，每次最多准备 2,000 笔有效唯一流水；当前样本为 257 节点、256 条聚合边。旧图谱响应的金额仍经 binary64 转换，图谱样本明确排除大金额哨兵，只校验普通金额的汇总与交易计数。Excel 使用现有 `main.export_tracked` 并计入临时文件写入，最多 10,000 笔，包含大金额哨兵；回读逐笔金额文本、前导零账号、方向与顺序，并确认待调取账号工作表存在。

## 计时与资源口径

分阶段记录 CSV 解析、`analyze`/`build_rows` 清洗、`commit_rows` 原子写入、同案重复导入去重、精确统计、两页有界分页、图谱准备和 Excel 导出。分页使用当前案件过滤和 `trade_time desc, id desc` 排序，各取首部与深偏移位置最多 100 行；统计及分页测现有业务同口径 SQL，不依赖新建 API。文件生成、应用启动、完整性核验与显式 checkpoint 也单列。worker 总计时覆盖 `run_sample` 的测量区间，包含这些阶段和准备/核验工作，解释器启动前开销与退出清理另属进程生命周期。

壁钟来自 `time.perf_counter`；CPU 来自 `time.process_time`，包含该 Python 子进程及其线程的 CPU 时间。RSS 使用 POSIX `ru_maxrss`（Windows 路径为 `PeakWorkingSetSize`），是**该完整子进程到当前阶段结束时的累计高水位**，不能当作阶段独占内存，也不能相减推算阶段用量。父进程仅收集小型聚合 JSON，不用父进程 RSS 代表子进程。Windows 分支尚未在本轮实机执行。

解析后的源 DataFrame 在清洗结束后释放；标准化行保留到重复导入和小型跨案夹具完成。图谱、分页与 Excel 均有固定上限，没有大规模浏览器布局或无限物化渲染结果。周期 checkpoint 调度器关闭，显式 checkpoint 单独计时；业务导入、事务和查询实现保持原路径。

每个阶段每个子进程只有 1 个观测值，三次重复报告中位数和 nearest-rank P95。**n=3 时 P95 就是三次最大值，只描述这些样本，不能估计稳定尾延迟。** n=1 的百万行记录只作容量观察。未丢弃预热样本；启动阶段使用空 Matplotlib 缓存，包含字体缓存构建。后续查询使用该子进程刚导入的数据库，未清空 OS 文件缓存，工作站也未锁频或独占 CPU。当前结果不满足演进建议中的 10 次冷启动/30 次预热采样规模，不据此启动技术重写或认定端到端产品性能。

## 2026-10-31：规范 JSON 编码原型排除

最终 100k 存量追加 10k 的连续观察依次为 **9.682089 → 9.105493 → 8.986349 s**，分别为历史筛选前、筛选后、行对象复用后；采样树峰值为 1538.578125 → 1578.109375 → 1518.968750 MiB。末项仅少约 119 ms，完成等待 4.430076 → 4.284069 s，首查反而为 1.602761 → 1.660450 s；不能把全部差值归于两个改动。这一追加试验复用了冻结基础库及输入，当前公开 CLI 不自动重建该历史现场，数值作为历史观察保留。

该末项 87 项定向回归及最终公共画布判例通过。257 行公共回归在旧实现实际解码 771 次，候选不超过 259 次；没有据此外推已实测的 10k 解码数。三份 110k 结果的全部 21 个非运行时钟流水字段、完整来源日志／关联、九张相关表和完整回执一致；仅按经原件 SHA 验证的来源 ID 及明确运行时钟归一。性能输入为 0 个确认事件／110k 个未决观察，复杂资金含义另由公共判例检查，不能拿这一性能输入替代它。

RSS 是约每 50 ms 读取自有服务进程树的同时 RSS 之和，实际间隔随调度变化；峰值是采样下界，共享页可能重复计数。目录与匿名文件大小是非原子的逻辑字节观察，不是物理磁盘可用空间。少量前后观察均不构成稳定提速、P95 或内存收益保证；未清 OS 文件缓存或独占工作站。已有完整字段、来源及回执对照复用，没有为本次集成重跑大样本或真实业务包。

### 未采用的试验
