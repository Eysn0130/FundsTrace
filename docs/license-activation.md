# 独立版授权与签发工具

**后续策略已调整（2026-10-15）：** 维护者决定后续 `FundsTrace v0.1.x` 安装包暂不要求授权码启动。以下保留 alpha.2／alpha.3 的授权实现和维护操作，不再作为下一版用户启动前置条件。当前源码及 v0.1.0 已移除正常启动的许可门卫；已发布 alpha.3 保留原流程。已有私钥、口令和签发工具继续保留，不因暂停激活而删除。见 [发布规则](desktop-delivery.md)。

下述为历史离线激活流程及保留的验签／签发 API；当前页面已改为免激活提示，普通用户无需操作。`FundsTrace Issuer` 是维护者使用的独立 Electron Windows 应用，具有独立 appId 和运行目录，不连接案件数据库。普通用户只安装 FundsTrace，复制机器码、取得授权码并输入激活。

新版 FT2 使用 Ed25519：签发端保存私钥，客户端只持验证公钥。旧 HMAC 仅在原部署明确配置 `FUNDS_TRACE_LICENSE_SECRET` 时继续兼容；不会把共享秘密加入公开安装器。Electron 的随机会话 token 仍只证明本地服务归属，不代替产品激活。

## 首次配置

以下操作供维护者首次部署或换钥使用，普通用户无需自行配置公钥。

1. 维护者打开 **FundsTrace Issuer**，输入至少 12 字符的私钥口令，选择“创建密钥对”。先为私钥和公钥选择两个新文件名；取消不生成文件，已有文件不覆盖。
2. 私钥以口令加密的 PKCS8 PEM 保存，仅由维护者保管和备份。工具退出后清除内存引用，下次须重新加载私钥。遗失私钥或口令不能从公钥恢复；不要把私钥放到源码、仓库变量、Actions 或安装资源里。
3. 将工具导出的 **SPKI 验证公钥**配置给客户端，任选其一：
   - 历史 alpha.3 构建曾使用 Actions 非秘密变量 `FUNDS_TRACE_LICENSE_PUBLIC_KEY`；当前 Windows 工作流不读取该变量，免激活客户端不再依赖它。
   - 本地构建：将公钥保存为源码根的 `activation-public-key.pem`（已忽略），再运行 Windows 构建脚本；不要与上述环境变量同时使用。
   - 已安装版的维护配置：在 Windows 用户环境变量中设置 `FUNDS_TRACE_LICENSE_PUBLIC_KEY_FILE` 为公钥文件的绝对路径，完全退出并重新打开 FundsTrace。此显式配置优先于包内公钥；由部署维护者管理，不通过网页上传或导入接口设置。
4. 客户端激活页显示公钥指纹；与签发工具的指纹对照后开始签发。未配置或配置损坏时保持未激活，并给出公钥配置提示。

`alpha.2` 历史安装器未内置生产公钥。`alpha.3` 预构建客户端已通过 GitHub Actions 非秘密变量内置分发公钥，公开指纹为 **`FEF434964FE89178`**；普通用户安装该版本后，只需提供机器码并输入维护者签发的授权码，无需自行设置公钥。签发私钥与口令不进入仓库或安装器。合成回归使用的 RFC 8032 公开测试密钥不会作为默认受信公钥打包。

## 日常签发

1. 用户把 FundsTrace 激活页显示的机器码交给维护者。
2. 维护者在 Issuer 加载私钥，输入机器码，选择日期或永久授权，再复制完整 FT2 授权码给用户。
3. 用户输入授权码；客户端校验产品、签名、机器绑定和期限，保存到独立数据目录 `license.dat`，重启后重新校验。

FT2 日期授权包含所选本机日期全天；旧 HMAC 的截止语义不在本轮自动修改。两者均不防系统时间回拨。改主机名、系统标识或设备信息也可能改变机器码。

换钥时，修改 Actions 公钥变量只影响后续重新构建的安装包，不会修改已发布包或自动更新旧安装版的公钥。安装并使用新公钥版本后，旧公钥签发的授权码会失效，须由维护者用新私钥重新签发；应在用户升级前安排好新授权码。

## 开发、构建与证据

```sh
npm --prefix desktop run issuer
npm --prefix desktop test
```

当前 `scripts/build-windows.ps1 -Installer` 仅构建免激活客户端。维护工具有需要时可单独执行 `npm --prefix desktop run pack:issuer:win`（Windows x64）；不作为普通用户依赖。FT2 跨语言签发和历史校验由 `tests/test_license_activation.py`、`tests/test_license_v2.py` 使用公开合成材料覆盖。包内烟测改为真实免激活启动，Actions 不接收私钥或口令。

Windows GUI、系统 DPI、实际安装和私钥对话框交互不作为预览发布的通过标记。源码 Electron 窗口检查也不能代替 Windows 实机验收。

后续接入 Analytix 时按宿主契约提供免激活入口；独立客户端的免激活不等于宿主权限，本轮不修改 Analytix。
