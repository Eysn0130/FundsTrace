# 自动资金数据导入

## 用户流程

选择案件后上传或追加CSV、TSV、TXT、XLSX、BIFF8 XLS及受支持的银行反馈ZIP。系统按来源结构识别字段，在每个工作表和表头区域内重新确定候选映射、单位和模式，然后校验全部记录。正常流程无需手工匹配或逐条裁决；已有高级映射和历史导入恢复仍保留。

完成页分别显示来源处置、新增流水、重复流水、已配对冲回、零金额、辅助资料和未确定记录。来源自动处理完成，不表示银行材料完整，也不表示每条来源都可以唯一解释成资金事实。未确定行保留来源、原因及对金额／关系分析的影响，不按零金额处理，不伪造账号、方向、时间或金额。

完整处理报告可在当前案件内下载，包含所有逻辑记录的处置、成员／工作表、原始行位置和映射依据。原始上传文件仍按既有留存策略保护；重复事实增加来源关联，不重复计额。

## 确定性解释

- 有限的完整别名与身份角色组合产生候选；整区域的所有明确候选参与校验，不按接受率、样本前几行或模糊置信度选规则。
- 分、角、元、千元、万元按Decimal精确换算，换算后验证分精度与范围；多个金额、单位、币种、方向或时间字段必须一致。单位不跨行、字段或工作表传播。
- 明确的带符号金额字段可解释正收入／负支出。普通负金额不因负号或退款字样单独获得新方向或成对冲回语义。
- 只有限定来源的闭合交易引用、状态、身份、币种及余额等证据满足既有配对规则，才使确定的冲正／撤销双方退出有效统计。普通退款不因文字相似被排除。
- 同笔交易明确的前后账面余额可在已定义契约下补方向；普通相邻余额不能证明账簿连续，不据此补造方向或金额。
- 完整且已验证的统一交易模板允许将查询帐号／查询卡号识别为对应本方账号／卡号；普通查询条件、任务号、姓名、辅助资料或跨文件相等值不提供主体授权。

普通表格默认规则为`funds-trace-table-v17`，历史v5—v16保留原解释。v15修复数字名称额外列阻挡区域换表头的问题；v16在旧金额不可解析且新结构完整时识别日期名称的额外列；v17继承这些能力，只增加完整标题`币种代码`的币种候选，以及旧日期／金额可解析时的局部表头歧义保护。币种候选全部参与合法值、相互一致、公式和金额单位校验，空值及无币种材料沿用历史默认。正常交易和部分标签保持原保护。银行反馈及archive仍使用各自固定版本，不能互换来源语义。

仅BIFF8 XLS采用`funds-trace-table-v18`读取语义，继承v17的确定性字段与区域保护；CSV/XLSX仍默认v17，历史v5—v17仍拒绝XLS，v18不能用于其他后缀。会话重预览与提交继续使用首次固定的版本。读取前校验OLE/BIFF8子流、工作表身份和公式位置；只导入普通工作表（含隐藏表），可闭合的图表、宏表、对话表不作为交易且不执行。未知或不闭合结构、旧VBA模块子流及仅非交易工作表的输入明确拒绝，不扩展ZIP成员类型。

XLS按1900/1904日期系统解释已编码的日期、时间。非时长日期单元格的serial不少于1时保留完整日期时间，不因显示为月份或时刻而截断；1900的serial60及date格式的0至不足1不能伪造日期，1904的serial0是1904-01-01。0至不足1的明确纯时刻格式保留time，不给缺日期的数据补日期；负数、非法日期及[h]/[m]/[s]等时长不转换为交易时间，无法判明的格式不猜测。关键字段公式不采用缓存入账，错误、布尔和无法解释的日期保留`invalid_cell_type`；辅助公式不连带拒绝正常交易。共享公式仅标记实际公式单元格，不把范围中的普通字面值当作公式；数组公式按完整范围核验。文本长账号/卡号与前导零保留，数值账号继续受15位安全门槛和明确补零格式约束，不能恢复Excel已损失的数字。

完整的新表头若复用了旧身份字段位置，同时旧日期和金额也可解析，同一来源可能解释成不同的交易双方、时间和金额。v17不会优先猜其中一种：该行及后续受影响区域保留`ambiguous_region_header`原因，至下一无法按任何实际竞争布局的日期／金额坐标构成交易的完整明确表头恢复自动处理；额外列的数字和日期不构成新的强制门槛。其他工作表和既有明确区域不受影响。仅在额外列出现完整表头词汇仍按正常交易处理，不把合法文本账号或卡号加入黑名单。歧义区域单独作为文件首表头时只有一种既定映射，拼接后增加了另一种解释，不能在缺少边界依据时承诺两者必然产生相同资金事实。

新ZIP采用archive-v4，仅将精确“币种代码”识别和上述重叠区域保护补入原成员规则，继续使用v3已验证的取消政策；不把整个成员解释切换为v17。显式v1/v2/v3及旧ready固定版本继续保留。若有v4评估参与，同一物理来源的完整资金事实或本方身份与历史解释冲突，本次保留`conflicting_field`原因及来源，不新增或冒充重复。物理匹配限同完整ZIP成员路径，或与合格普通CSV的同字节、同行直接对应，不经普通CSV传递归并不同ZIP路径。v4已确认的币种矛盾／区域歧义也不能被旧ready重新接纳；历史冲突持续计入分析缺口，已有错误币种或区域解释不在本次自动改写。此保护在已有来源详情中保存专用冲突依据，旧ready也可保留该依据；未参与v4的旧表格历史冲突继续使用原有版本覆盖规则，不因同案另一份无关v4来源改变口径。

## 入库、统计和恢复

规范流水、账户、来源关联、逐记录处置与耐久回执在同一数据库事务内写入并回读核对；失败回滚，不留下部分批次。来源原件不变，处置日志存解释及定位信息，没有新增Raw/Clean双份业务账表，也不使用运行时大模型。

同一CSV原件先单独导入、随后装入受支持ZIP时，先保留已有完整成员身份的匹配；其余记录仅在字节摘要、物理行、完整资金事实及本方身份均与同案普通CSV一致时复用旧流水。每条旧流水在本批至多复用一次，包内不同路径／物理行仍保留独立出现次数；日志继续记录完整成员路径，不重写历史事实，也不合并不同字节的相似材料。

archive-v4已闭合的成对冲正证明可直接关联同案、同字节、同物理行的合格普通文本CSV，避免仅因ZIP成员改名而重复计入原交易。原交易、冲正和见证位置的实际历史事实与适用冲突均参与验证；失效证明及其见证依赖链不提供新共享，独立配对保留。共享不使两个不同ZIP路径等价；一个流水的全部来源关联分别具有排除证明时才从有效金额排除。普通CSV仅有`negative_amount`这一项诊断且对应有效冲正位置时，解除当前分析缺口，原负数处置日志、原件和旧回执不改，取消记录数仍只数ZIP实际取消评估。其他错误、未知规则、不同字节／物理行及无证明的退款负数仍保留原诊断。旧v3案件不会因打开新版自动获得新共享，须追加v4评估；历史已存在的重复流水不删除。

原始事实、有效资金及图谱展示去重有不同口径。`effective_flows`只依据已验证排除证明筛选统计输入，原流水与来源仍可追溯。统计、账户画像、分析、追踪入口和Excel导出使用同一有效事实口径；图谱保留120秒容差与FIFO，配对仅允许明确属于交易双方的本方，详见[money-contract](money-contract.md)。图谱渲染与布局不变。缺对手的可靠流水可以保存，缺少账户身份的侧不能被猜成关系节点。

提交回执丢失或首次进度读取失败时，保留案件和导入绑定，仅查询原任务进度，不自动重放提交。主线的父级导入lease、隐藏后台保活、账户操作互斥、换案撤销及耐久回执恢复继续有效。金额含义未确定和网络结果未确定分别处理，恢复进度不要求用户裁决银行流水。

## 兼容和限制

旧数据、历史规则和已就绪会话继续可读；新解释不会覆盖已有不同资金事实。案件包保留来源元数据与处置证明，恢复时重映射关联、重新验证完整性，但不包含原始上传字节或导入任务回执，也不自动重放写入。

无新增来源日志的案件继续使用原案件包格式；银行日志可采用格式3，含自动表格日志采用格式4。当前应用支持历史格式1/2及格式3/4，旧应用会拒绝其不支持的新格式。回退到旧应用应使用其能够解释的数据与备份，不能将历史规则兼容等同于旧程序能理解新增来源语义。

无后缀文本按原入口默认CSV导入并保留原名。其案件包恢复仅接纳普通非XLS规则、空工作表、恰一`table.csv`文本成员，且成员角色、编码、字节摘要和大小与来源合同闭合；随后仍执行完整日志及实际资金事实校验，不给Excel、ZIP或无日志的旧来源新增通用放行。案件包不含原件字节，这项校验不能重新鉴定缺失的原件。

XLS支持范围为未加密的OLE/BIFF8（Excel 97—2003）普通工作表，不支持旧BIFF、HTML伪XLS、XLSB、公式或宏执行。加密／损坏文件、危险ZIP路径、结构歧义及超出安全资源限制的输入不静默接纳。未定义银行代码、缺失关键数据、不可消解冲突仍可能无法形成可靠资金事实。此能力不承诺未来任意银行格式百分百自动还原。

## 本PR范围和验收

本PR从当前main迁入导入解析、精确校验、原子持久化、来源报告、案件包及必要调用方，保留主线新增的账户工作区、分析入口、照片校验、上传失败恢复和宿主绑定。没有修改桌面宿主、安装器、发布流程、许可、图谱渲染／布局／主题或品牌资源。

迁入时额外用合成反例修复了旧明细接口遗漏有效事实筛选、普通表格Excel导出遗漏完整性说明、旧入口截断自动映射、恢复已完成任务丢失原件文件名四项接入问题。相关测试保留明确的金额／来源／案件断言；旧规则测试固定历史版本，当前默认另行验证全量处置。

验证使用合成交易和独立临时数据库，覆盖多工作表、区域换表头、单位与方向、末行冲突、追加／重复、两种版本提交顺序、跨案拒绝、失败回滚／恢复、format3/4及上游来源至下游统计。构建与浏览器验证为本机源码候选证据，不代表Windows安装版或真实银行全覆盖。
