日期：2026-10-23。源码基线：启动时核对的 `origin/main`，`97b757337d610a6556c6cd610de2bfdae55bf2ef`（PR #50 合并提交）。本地候选分支：`codex/canvas-investigation`。本次覆盖顶栏全部 13 个原“暂未开通”入口；本文记录源码候选与阶段性验证，不作为合并、正式打包或发布记录。既有工作目录的未提交修改保留在原处。

## 从研判任务到功能设计

使用者需要反复回答：哪些流水可信、当前正在看哪一部分、两端是否相连、时间顺序是否成立、哪些账户需要补证，以及如何把可复核的发现交给另一位使用者。单独启用按钮不足以完成这些工作，因此实现围绕“核对来源 → 追踪上图 → 限定范围 → 比较假设 → 整理线索 → 保存与交付”连接现有功能。

现有产品已经具备案件隔离、导入预览与持久化回执、查询与流水详情、追踪成员、图谱关系筛选、全案分析、画布保存和案件包。新增功能复用这些边界，保留原始流水、图谱镜像配对、显示筛选和分析结果之间的区别。

| 研判阶段 | 使用者的问题 | 功能联动与输出 |
| --- | --- | --- |
| 核对资料 | 哪些账户、时间、方向和来源仍有缺口？ | 导入／详情保留原始来源；分组备注记录待核问题；缺失资料不补造 |
| 建立工作范围 | 本次看全案、完整追踪图还是眼前局部？ | 案件与画布绑定；全案分析保持独立；图内路径明确选择完整追踪图或可见有向关系 |
| 检验连接假设 | A 是否能到达 B？是关系可达还是存在时间先后？ | 两种路径模式分别回答；限定同币种和最大跳数；逐跳金额与来源可展开 |
| 检验时间假设 | 事件前后发生了什么？关系金额是否来自窗口外？ | 时间窗口按实际有效流水重算；播放逐个交易时间累计；无时间记录单独处理 |
| 整理补证与解释 | 哪些账户属于同一研判问题？如何保持图形稳定？ | 多对多人工分组、备注、形状、图标、下划线、固定位置；不据此合并身份 |
| 复核与交接 | 下一人能否知道范围、条件和依据？ | 具名画布／案件包保留设置；路径 JSON 保留参数和完整引用；图谱导出注明范围 |

设计参考 [FATF《Operational Issues — Financial Investigations Guidance》(2012)](https://www.fatf-gafi.org/content/dam/fatf-gafi/reports/Operational%20Issues_Financial%20investigations%20Guidance.pdf)：第 2 段（正文第 3 页）强调梳理资金来源、受益人、接收时间与存储位置；第 23 段（正文第 9 页）强调银行记录及资金活动的书面轨迹；第 49–50 段（正文第 17 页）讨论形成假设，再确定检验假设所需的信息。本实现据此把范围与逐笔依据放在路径及时间操作中；这是产品设计取舍，不是法律认定规则，也不证明软件或单一图谱满足取证要求。

## 金额、路径和时间语义

### 事实来源与时间投影

只读取当前案件及画布的 `effective_flows` 与 `tracked_flows`。保持现有 FIFO 镜像配对规则：在完整画布、原时间／ID 顺序上配对，然后按代表流水的原始交易时间筛选。镜像 ID、原始记录时间及来源引用仍可追溯。窗口边界不改变哪个记录代表图谱交易，也不把镜像认定为新的独立转账。

统计使用 Decimal，API 金额与流水 ID 使用字符串；CNY、USD 及未标注币种分别保留。时间不转成 UTC、不推测时区，保留微秒；数值时间与带时区输入被拒绝。时间表单采用带格式说明的文本输入，避免原生日期控件把六位小数秒清空；不同小数位数的相同时间按等值比较。没有可上图端点的记录不会虚构节点，统计说明排除数。

启用“金额 → 线宽”时，时间窗口及每个播放帧都按窗口内完整追踪图的关系金额重新计算统一线宽比例。邻域、账户隐藏和关系筛选不改变该窗口的标尺；不同时间窗口或播放帧的标尺可能不同，应结合金额标签和当前窗口图例比较。关系金额筛选的预计数量与实际应用使用同一时间投影，再叠加邻域及账户显示条件，避免把全时期金额用于窗口内筛选。

新增只读接口：

- `POST /api/canvas/investigation/time`：窗口内账户、关系、逐笔依据、分币种合计、时间轴与范围计数。
- `POST /api/canvas/investigation/paths`：同一事实源上的有向简单路径、逐跳金额与流水引用、范围参数与完整性说明。

两条接口都在数据库锁内核对案件和画布归属。可见范围要求同时提供账号及实际有向关系集合，避免只检查节点而把被隐藏的边重新纳入搜索。它们不改变现有 v1 契约。

### 两种路径回答不同问题

关系模式把同方向、同币种的流水聚合为边，查找不重复账户的可达路径；不声称这些交易存在先后。严格时序模式逐笔搜索，要求下一跳时间大于上一跳，并排除无时间、未知币种和非正金额；同一时间的两笔记录不能据此排序。两种模式都不跨币种拼接，不把各跳金额求和当作同一笔本金。

结果可展开代表流水、镜像和已有导入文件／行／成员路径／SHA-256／解析版本。ZIP 来源分别显示成员文件路径及其原始行号、包内记录号，不把包内记录号当成成员文件行号；普通文件保留其来源行号。缺少来源时界面明确说明；单跳界面最多展开 50 笔，完整 JSON 包含该结果的全部依据与查询参数。

搜索限定 1–8 跳，界面最多 30 条（接口上限 50 条）；最多检查 50,000 个候选步骤、排队 10,000 个状态。达到显示或工作上限会返回明确截断原因。`complete` 仅表示本次所选范围、时间、币种和跳数以内的简单路径搜索是否完整，不等于全案穷尽，不提供资金归属、风险定性或最优路径证明。

完整画布最多读取 20,000 条有效流水、来源最多 80,000 个引用；超过上限整体拒绝并提示缩小画布，不返回看似完整的部分金额。此界限是本次实现的保护条件，不是性能承诺。

## 状态、持久化与导出

`static/canvas-investigation.js` 管理对话框、时间投影缓存、播放和路径结果；`static/graph-presentation.js` 校验及序列化分组、时间窗口、节点图标／形状、下划线和固定账户；`static/app.js` 将其接入原图谱渲染、快照、历史和导出。布局约束仍在现有布局模块执行，没有另建业务事实图或修改 G6 供应包。

所有请求绑定案件、画布代次和完整图源。切换案件／画布、同一案件重新绑定、源数据刷新后，旧请求和对话框失效；A–B–A 也不能接收旧结果。时间投影读取中或失败时显示空范围及读取／重试说明，避免在窄时间标签下展示全期金额。单次失败不会自动无限重试。

播放帧使用递增意图标记；暂停、切换、编辑及后续帧能使迟到回执失效。播放遇到拖动、布局、历史或导出时暂停；不以逐帧渲染覆盖正在进行的编辑。编辑命令被拒绝时保留输入并显示失败，不宣称保存成功。“应用当前帧”被拒绝时保留暂停的临时预览及其范围，待当前操作完成后可重试；“结束预览”遇到布局等忙碌状态时也保留预览并提示稍后重试，不通过重绘中断布局。

历史只记录显示、账号 ID、几何和范围。完整画布快照仍使用完整图的统计、节点角色颜色和尺寸，而非当前时间窗口的投影；分组／形状／图标／下划线／固定位置／时间设置随具名画布和 `.fundcase` 往返。保存播放时不隐式提交临时帧；明确“应用当前帧”才改变持久时间窗口。

PNG／PDF 使用打印样式，图下不附加范围说明块；实际时间、筛选范围及标签设置保留在导出窗口，并分别写入 PNG 的 `Description`、PDF 的 `Subject` 元数据。HTML 保留离线交互、样式及范围说明；标签、分组、图标、固定标记及下划线参与导出。导出沿用真实连线的标签锚点及手动位置，不增加导出专用的避让偏移，因此不保证密集图谱的标签没有重叠。Excel 沿用完整已追踪流水范围。返回全图清除时间及局部显示限制，不删除分组或事实。

PNG 后端重新编码保持 RGB／RGBA 像素及尺寸，不保证压缩字节一致。PDF 在没有可用 img2pdf 时以 Flate 压缩嵌入完整 RGB 图像，保留原分辨率和既有 288dpi 页面几何，不再量化为 256 色；透明图像仍按原规则铺底。回归对解压图像逐字节比对，并核对页面矩阵、中文元数据和压缩体积，img2pdf 分支只验证调用参数。文件元数据不会随打印显示在页面上。

### 后续 P2 修正与复核

具名画布原来的 250ms 首次适应会遇到尚未完成的时间投影，随后渲染又使旧任务失效。现在只为打开快照保留一次适应意图，等待精确窗口就绪后按可见图适应；空结果直接消费意图。用户调整镜头、改变窗口／案件／画布、开始新布局或导出会取消旧意图，播放帧不获得自动适应权限。此次只改变镜头与 PDF 编码，不改变流水、精确金额、保存坐标或文件格式。

本次仅用 12 节点、11 条合成流水，窗口内 3 节点、2 条关系复核：

- 公共 `loadCanvas` 延迟超过 250ms 的复现先失败、修复后通过；图交互 Node 回归 396 项、研判控制器 32 项通过，覆盖缓存／空结果、手动镜头、窗口往返、A–B–A、布局、导出及播放。原有坐标、手工折点和标签比例有不变断言。
- 实际浏览器将投影网络延迟设为 800ms，观测请求耗时约 805ms；重开及另存后均自动适应 3 个可见节点。另在读取期间手动放大，迟到结果没有覆盖手动镜头。测试后恢复正常网络。
- 重开前后实际导出 HTML 的内嵌图谱数据完全相同，含方向、`9999999999999999.99` 与 `0.01` 金额、节点坐标、菱形、旗标、下划线和固定设置。该实际样例的连线为自动路径；手工路径及半透明输入另由合成回归覆盖。
- 同一份 7344×3276 浏览器采样输入，旧回退 PDF 为 48,737,850 字节，新回退为 323,067 字节，减少约 99.34%；页面尺寸与中文 Subject 相同，解压 RGB 像素逐字节相等。另从修复后界面实际下载 PDF 为 289,583 字节，单页，72,176,832 个 RGB 字节与实际 POST 原图完全一致。主 Agent 打开 PNG 与 PDF 页面渲染复查，金额、时间及连线位置清晰，未增加底部说明。
- PDF 公共 API 回归 35 项通过（RGB／RGBA、缺失／失败的 img2pdf、精确中文元数据、页面矩阵、体积）；全套 Python 运行首轮 3160 项通过，1 项仅因工作树缺少 `.venv/bin/python` 入口而失败，补齐本地入口后该项单独复跑通过；API 契约与 G6 哈希检查通过。PR CI 另确认提交版本的全套结果。

压缩率取决于图像内容；PDF 仍为单页栅格图，不新增可搜索矢量文字。实际 img2pdf 优先分支保持原行为，测试仅模拟其调用契约。本次未打包或发布，不构成 Windows 安装、混合 DPI 或真实案件验收。
