# 工作台使用指南

基础工作台最初随 [v0.1.1](https://github.com/Eysn0130/FundsTrace/releases/tag/v0.1.1) 发布；本文的快捷键、路径及环路说明以当前源码为准，已发布安装包的功能以对应 Release 为准。Windows GUI、DPI与真实浏览器缩放尚未实机验收；源码、浏览器与原生安装检查分别记录。使用说明之外的证据见 [设计验收](../design-qa.md) 和 [桌面交付](desktop-delivery.md)。

## 查询与空间调整

1. 先在顶部选择案件，再选择要编辑的画布。
2. 填写账号、户名、对手、金额或日期条件，点击“查询”；输入框内也可按 Enter。“仅已上图”按当前画布筛选。
3. 点击“筛选”可单独收起查询表单。条件摘要、结果数、表格工具、批量追踪和全览入口仍可使用。修改但尚未查询的条件标为“待查询”，旁边的数量注明为上次结果。
4. 左侧查询区和顶部工具带可分别收起。悬停或用键盘聚焦边缘中点按钮后点击切换；左侧分隔条可拖动，也可聚焦后用左右方向键调宽，按住 Shift 加大步长。缩小窗口会限制实际侧栏宽度，放大后恢复本次页面内选定的宽度。

流水表保留七列，账号与金额完整显示。可切换行距及“完整换行／完整单行”；列宽不足时使用表格自身的横滚或底部滚动控件。查询失败时会标明是否保留了上次结果。

## 锚点与上图是两种操作

| 位置 | 第一列含义 | 勾选后的动作 |
| --- | --- | --- |
| 左侧流水表 | 追踪锚点 | 选择批量追踪的起点；再设置来源／去向与最近笔数，点击“追踪上图” |
| 流水全览 | 当前画布的上图成员 | 勾选立即加入当前画布，取消勾选立即移除该笔流水 |

左侧“本页锚点”只选择当前页。批量追踪能否继续延伸取决于主账号及实际流水；完成提示会说明跳过情况。普通查询刷新、翻页和开关全览保留已选锚点，切换案件或画布会清空临时锚点。

## 使用流水全览

点击表格工具区的扩大图标打开居中全览。全览与侧栏共用同一份查询结果，保留行距、文本设置和分页；两种视图各自记住本次页面内的滚动位置。表头固定，内容独立滚动，窗口不足时仍可局部横滚。

- 第一列“上图”显示当前画布的追踪成员。可逐行勾选，也可使用“本页全部上图”；其范围始终是当前结果页。
- 连续勾选或快速反选会按最新意图排队收敛。行内显示“添加中／移除中／已上图／未上图”，处理过程中仍可继续选择。
- 明确失败会回到该行已确认的状态，并显示“失败 · 重试”。再次勾选或取消该行即可重试；其他已成功的操作保留。
- 通过关闭按钮、Escape 或真正外部遮罩关闭。表格、滚动条拖动到外面不会被当作关闭。关闭只收起视图，已经发送及仍属于当前绑定的排队操作继续处理。
- 全览没有额外确认页脚。改变上图成员后，可用全览中的“撤销／重做”调整；操作进行中相应按钮会暂时禁用。勾选保留已有节点位置和相机视图。

表格行可用上下方向键移动焦点，空格勾选，Enter 打开流水详情。全览中的空格执行上图成员变更；侧栏中的空格选择追踪锚点。结果刷新后保留同一流水控件的焦点；该行消失时焦点回到表格区域。

## 撤销、保存与切换

顶部“撤销／重做”按钮提示下一步动作。关闭对话框且焦点不在输入控件内时，可用 Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做；全览内直接使用其按钮。

历史覆盖上图、移除、清空画布、布局、显示、邻域、主体标注及几何编辑。双击节点进入邻域同样记为一步“查看账号邻域”，撤销一次即回到进入前的完整图谱与相机；焦点离开图谱后快捷键依然有效。一次提交的批量上图记为一步；快速反选如已经形成多次服务器写入，可能对应多步历史。单纯折叠、查询、分页、开关全览、平移或缩放不会新增历史。历史只保留在本次页面内，最多40步、约8MiB；刷新、切案件或切画布都会清空。

画布文件区直接提供“新建画布”“另存为”“删除画布”；“删除画布”仅对具名画布可用（默认画布是案件数据落点，按钮会禁用并说明原因），确认后连同该画布的上图成员一起删除。自定义标注：选中一个账户点“添加标注”，输入文字并选择起始位置——“节点文字下方”或“图形正上方”。标注是节点的一部分，拖动、布局、缩放时随节点一起移动；按住标注本身可做相对锚点的微调；新增、编辑、删除和一次拖动各记为一步撤销。拖动取消或切换画布会放弃未完成的微调，不写入另一画布。标注支持多行（文本框内回车换行，最多 6 行 / 200 字，每张画布最多 200 个标注），可设置字号、字体（默认／微软雅黑／宋体／黑体／楷体／仿宋）和颜色；标注随画布保存，也出现在 PNG／PDF 及离线 HTML 导出里，颜色在导出时保留（打印样式只把图谱自身的文字转黑）。标注保留用户的相对位置，手动放到其他节点文字上时不会自动搬移；“图形样式 → 恢复默认”会一并清除。
“保存”记录当前画布形态，默认画布会提示另存为具名画布。上图变更即时写入当前画布；保存形态与勾选上图分别生效。导入、删除案件／画布、身份和照片资料等操作不属于画布撤销历史。

切换案件或画布时，全览关闭，旧结果和临时锚点立即清空，目标画布就绪后重新查询。未发送的旧绑定操作取消；已发送操作可能在原画布完成，迟到回执不会写进新界面。原案件数据和已完成的上图成员仍保留。若提示追踪状态无法确认，请重新选择画布或刷新页面读取状态后再继续。

## 导入与失败恢复

点击“导入流水”，选择 CSV／Excel 文件，核对预览、字段映射及本方账号，再提交导入。预览或重新识别失败时按提示检查文件／映射后重试。

提交后关闭导入窗口只隐藏进度。同一页面、同一案件内重新打开，会继续显示仍在进行或等待确认的任务。若提交回执或进度读取失败，点击“重新读取进度”：此按钮只读取已知任务的状态，不再次提交导入。只有明确失败后，才按提示检查并手动重试。切案后，旧任务的迟到结果不会覆盖当前窗口。

“导入批次”可查看案件内已有批次。当前窗口的进度恢复依赖本次页面会话，不承诺刷新或重启后自动恢复原窗口。

## 分析与导出范围

“全案分析”打开独立分析页并携带当前案件，只运行勾选的算法。分析使用案件已导入流水，不受工作台查询条件或当前画布成员限制。HTML 报告沿用最近成功分析的案件和参数，生成时重新计算；修改参数后应重新分析。

路径起点与终点可填账号或户名，账号精确命中优先；户名按全部流水中出现的名称匹配，多个同名账号都作为候选。“金额优先”在本次候选中按交易边合计降序；“时间优先”优先展示时序连续的路径，再按首跳时间升序。每条路径列出首跳、末跳时间；交易边合计不等于守恒本金。

环路检测要求交易方向首尾相接、每跳时间不早于上一跳，且落在环流时限内。指定分析对象时筛选**包含该账户**的闭环，展示仍从实际时序起点开始。相同账户环的多组交易保留本次候选中回转比例最接近 100% 的一组，再按比例接近程度排序。回转比例是末笔回流除以首笔转出，显示为近似值；时序和比例都是复核线索，不能证明同一笔本金流转或异常性质。

路径和环路均为**有界搜索**：受跳数、邻居／起点数量、工作预算与显示数量限制，按币种独立处理。排序针对本次搜索到的候选，不能视为全案最优或穷尽枚举；结果受限时界面和报告会提示，零结果也只代表本次搜索未发现。API 的 `search.complete` 说明搜索是否受保护限制，`search.result_limited` 说明显示是否截断；`truncated` 汇总两者。

每条环路可“一键上图”，服务端在同一事务中创建专属画布并添加该闭环的流水。重试仅复用带分析来源标记且**当前流水集合完全相同**的画布，不按显示名识别，不向同名用户画布追加。写入失败整体回滚；网络回执不明时可重试读取同一完整结果。切案或重新分析后，已发送操作可能在原案件完成，迟到回执不会进入新结果。成功后可在新窗口“打开独立画布”，原分析结果保留；链接携带案件、画布和首笔流水目标，加载及布局完成后选中首笔关系边并聚焦两端账户。

| 入口 | 导出范围 |
| --- | --- |
| 导出 → 图谱 PNG／HTML／PDF | 当前图谱视图；处于邻域时仅含当前邻域，需完整图时先点“返回全图”；PNG 与 PDF 为**白底黑字**的打印样式（节点与关系保留原配色，背景与文字改为白纸黑墨），HTML 仍为深色可交互版本 |
| 导出 → 追踪流水 Excel | 当前案件、当前画布的已追踪流水，包含“追踪流水”和“待调取账号”两张表 |
| 案件管理 → 导出当前案件包 | 当前案件的数据及画布等关联资料，用于案件包导入／迁移 |
| 全案分析 → 生成 HTML 报告 | 最近成功分析所选算法和参数对应的 HTML 报告 |

图谱导出保留相应布局与标注策略；保存画布保留完整图数据。下载开始提示与文件实际落盘是两个阶段，应在浏览器或桌面保存界面确认结果。
