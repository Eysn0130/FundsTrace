# 输入联想、查询与画布定位

本次按已确认的 1／2／4 方案实现：宽且内容放得下时使用紧凑同行；窄框或完整信息放不下时按姓名／证件、完整账号分行；实际命中账号时把完整号码放在第一行。候选为无表头、无操作栏的平面结果列表，不把流水表改成卡片。缺失证件不补占位，同名不同账户不合并。数字查询也可能命中证件，不能仅凭全数字就认定为账号。

## 各入口的业务边界

| 入口 | 候选范围 | 选择与补全 | 显式执行 | 画布 |
| --- | --- | --- | --- | --- |
| 图内查找定位 | 当前画布当前显示范围的账户 | 选择明确对象后定位；Shift+Enter只补文字 | SVG／Enter执行查找；多结果供选择，原批量命令保留 | 只移动镜头；不添加节点、不改选择或追踪事实 |
| 流水查询「账户」「交易对手」 | 当前案件有流水的账户，包括未上图账户及其证件关联 | 选择只填入并绑定完整账号；手改或补全解除精确绑定 | SVG／Enter执行完整流水查询；自由输入查询全部匹配，候选页不是查询全集 | 查询非空后预览当前可见对象；明确选择按原账号精确定位，缺席时不回退到包含号 |
| 户名包含、关键词、金额、日期 | 原有条件 | 原生条件输入 | 统一查询按钮执行；条件按原有AND组合 | 只有账户相关条件参与定位；关键词／金额／日期单独查询不动镜头 |
| 主账号管理 | 当前案件有流水的账户 | 选择只填写，补全不写标记；重复查询保留精确账号 | SVG提交后读取管理结果；添加仍是原独立命令 | 查询不动镜头；结果行靶心只对当前可见账户启用 |
| 账户与身份页 | 当前来源标签下的流水账户或身份对照记录 | 选择只填入完整账号 | SVG／Enter查询账户列表；查看资料、保存证件、主账号变更分别执行 | 不自动定位 |
| 全案分析起点／终点 | 当前案件有流水的账户 | 选择只填入账号 | 仅「开始分析／重新分析」运行 | 不自动定位 |
| 全案分析对象 | 当前光标词段；逗号、分号、空白分隔 | 仅替换当前词段；跨分隔符选区不联想；关闭幽灵补全 | 仍由分析按钮运行；空对象保留全案语义 | 不自动定位 |
| 案件筛选 | 已加载的案件名单 | 候选只筛选，Shift+Enter只补文字 | 点击原案件按钮才切案 | 不定位 |
| 新建／重命名案件和画布、备注、标注、证件编辑、导入归属、数值与日期等 | 无实体候选 | 保留原生编辑与校验 | 原有独立命令 | 不套用节点定位 |
| 共享FundsPanel的条件输入 | 原有宿主会话契约 | 保留原生条件 | 宿主原有查询 | 不绕过宿主授权直连legacy候选接口 |

## 滚动、反馈与撤销

- 候选请求合并等待140ms；每页30条，服务端最多50条。空文字不扫描候选全集；不逐键读取账户profile或完整count。正式查询仍返回真实总数及分页，不以30条候选截断查询。
- DOM采用变高行虚拟滚动，最多70个可见／缓冲选项，加一个必要的ARIA活动代理。载入3030条的合成行为检查中DOM不超过71个选项；不代表把十万条一次绘到浏览器。
- 浮层保留在原表单／对话框的DOM子树，通过原生Popover顶层显示；避免裁切、父菜单误关以及原生dialog的inert冲突。Chromium使用持续可见的9px细滚动条。滚轮不触发选中，不把默认滚动阻止掉；列表边缘阻断滚动串到背景。
- 上下键、PageUp／PageDown、Home／End浏览候选；Tab保留原生焦点行为。第一次Escape只关候选，第二次才交父弹层。中文组合输入不接受候选、不提交查询。分析textarea的Home／End保留光标行为，切词段撤销旧候选。
- 请求绑定案件、来源、输入、会话及数据版本。新输入立即撤旧选项；关闭、切案（含A–B–A）、切屏、数据刷新与禁用状态废弃旧结果。迟到响应不能写回，账号与证件全过程保持字符串。
- 仅在输入框聚焦、光标位于末尾且没有选区或水平滚动时，为原值前缀提供浅色补全文字。光标／选区改变后即时重算；单行框的Shift+Enter只补入仍有效的后缀，没有后缀时保持原值，不选实体、不查询、不保存、不运行分析。多主体textarea保留Shift+Enter换行。点击已聚焦的输入框可重新打开被Escape或数据刷新收起的候选。
- 主账号SVG提交后收起候选，自动焦点回退不重新展开同一查询；继续编辑新草稿或查询结束后主动点击输入框仍可查看候选。候选关闭后的Escape由外层弹窗处理，不触发原生搜索框的清空行为。
- 候选只显示户名、完整账号、已存证件和必要的原始别名。证件为账户已有对照记录，不表示身份已经核实。不显示教程、匹配评分或批量操作按钮；仅保留加载、无结果和失败重试的必要反馈。

## 验证范围与后续

生产实现复用已有浅色／深色／跟随系统外观及字体、对比、焦点与低动画设置，不新建另一套主题。桌面后端显式资源清单包含四个新JS／CSS文件；这只是资源检查，不是打包或安装验证。

十万账户、100039笔流水、40个上图节点的本机合成检查，以及浏览器记录见项目根目录 [design-qa.md](../design-qa.md)。不使用真实业务数据或原fund-tracker目录。

当前检索是原文字面包含、前缀和精确分级；不是拼音、错别字纠正或相似身份推断。DuckDB候选读取仍需扫描案件源并排序；HTTP取消会撤销前端结果，不承诺中断已开始的数据库语句。百万规模、慢硬盘与写入竞争仍应单独采样。偏移分页不提供不可变快照；本界面在已知导入／身份更新时撤销候选，其他进程直接改库不在本轮保证范围内。

未执行Windows GUI／DPI、真实系统输入法候选窗、屏幕阅读器实机、触屏实机与长时间内存采样。案件筛选沿用原有全量案件读取；若案件名单本身达到大规模，需另设案件分页契约。

设计取舍参考用户提供的 [Open Claude UI](https://github.com/Caho1/open-claude-ui)、[UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)、[Taste](https://github.com/Leonxlnx/taste-skill)、[Impeccable](https://github.com/pbakaus/impeccable) 与 [Apple Design](https://developer.apple.com/design/)；只采纳与本地高密度检索相符的层级、减法和反馈，不复制其产品导航。键盘与浮层边界另参考 [WAI-ARIA Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)、[Popover](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/popover) 和 [overscroll-behavior](https://developer.mozilla.org/en-US/docs/Web/CSS/overscroll-behavior)。
