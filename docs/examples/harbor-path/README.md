# 云杉项目 · 合成路径演示

一笔 480,000.00 CNY 项目预付款，经三路转出后，在另一账户归集。本例包含 **12 笔流水、7 个账户、8 条有向关系**，用于练习导入、追踪、画布整理与导出。

**名称、账号、交易、日期和业务背景全部虚构。** `SYN-` 账号不是可用银行账号，每笔摘要均标明“合成示例”。样例展示账单之间的时间与往来关系，不证明资金用途或交易性质。

[样例 CSV](fundstrace-synthetic.csv) · [样例 XLSX](fundstrace-synthetic.xlsx) · [导入 GIF](../../media/showcase/import-demo.gif) · [分析 GIF](../../media/showcase/analysis-demo.gif) · [真实工作台](../../media/showcase/workspace-focus.png)

## 样例中的路径

| 虚构主体 | 合成账号 | 演示位置 |
| --- | --- | --- |
| 云杉工坊 | `SYN-A001` | 首笔付款方 |
| 星桥商贸 | `SYN-B001` | 收到预付款后分三路转出 |
| 青禾工程 | `SYN-C001` | 工程款与补款 |
| 岚山物流 | `SYN-D001` | 运输服务款 |
| 汀兰材料 | `SYN-E001` | 材料款 |
| 远帆供应 | `SYN-F001` | 三路汇入后转至项目账户 |
| 松原项目 | `SYN-G001` | 最后收款方 |

日期为 2026-09-02 至 2026-09-13，单一币种 CNY。交易金额按原始两位小数保存，包括 `0.75` 尾款。CSV 使用 UTF-8 BOM，样例目录的 `.gitattributes` 固定 LF 换行以保留公开文件校验值；XLSX 将账号与金额保留为文本，避免电子表格改变账号或金额。

## 跟做一次

推荐使用 [最新 Windows 预览版](https://github.com/Eysn0130/FundsTrace/releases/latest)；也可按 [开发说明](../../../CONTRIBUTING.md#合成界面与本地启动) 启动临时合成预览。当前截图与 GIF 于 2026-10-20 采集，来自 macOS Chrome、0.1.8 源码候选的一次性合成预览，使用本轮统一的新应用图标。GIF 是直接由真实界面截图编码的步骤演示；不是连续录屏或 Windows 安装后验收。下文导出文件和逐笔核验记录保留此前采集结果，不能视为本轮重新导出或重验。

1. **新建专用案件**：在“案件管理”新建 `合成演示 · 云杉项目`。两个输入文件内容相同，只导入 CSV 或 XLSX 其中一个。
2. **导入并确认映射**：“导入流水”选择文件，确认识别为“单账户流水”。应显示共 12 行、可导入 12 行、跳过 0 行。演示只保留 `星桥商贸 / SYN-B001` 的主账号勾选，其他项取消；这是演示配置，不是限制只能选一个。点击“确认导入”。
3. **从第一笔延伸**：关键词查询 `SYN-PATH-001`，结果应为 1 笔 `480,000.00`。将它勾为侧栏追踪锚点，方向选“去向·收款方”、最近 5 笔，点“追踪上图”。应得到锚点加星桥商贸之后的 4 笔转出，共 **5 笔**。最近笔数按时间先后取最近若干笔，不是递归遍历整条路径。
4. **补齐完整样例**：“重置”查询，打开“展开流水表”，点击“本页全部上图”。应为 12/12 笔已上图，关闭全览。侧栏勾选表示锚点，全览勾选才直接改变当前画布上图成员。
5. **整理与保存**：在“视图”中选择“资金流向分层”，勾选金额、选择全部标签；可拖动节点调整留白，再“保存”为 `分流与归集 · 合成路径`。GIF 与主图使用的都是现有布局、拖动、缩放和显示功能，没有改动图谱渲染代码。
6. **实际导出**：打开“导出”，选择“Excel 追踪流水”后导出；再选择“PNG 图像”导出。确认下载已保存到磁盘。完整图先退出邻域，避免只导出局部视图。

## 再看一次路径分析

在“全案分析”只勾选“路径追踪”，起点填 `SYN-A001`，终点填 `SYN-F001`，最大跳数填 `3`。点击“开始分析”后应得到 **6 条路径**；“生成 HTML 报告”确认后下载本次参数重新计算的报告。

这是交易边组合形成的拓扑路径：青禾线路有 2 × 2 种边组合，岚山和汀兰线路各 1 种，共 6 种。金额是路径上交易边的累加，非去重本金，也不保证交易时间递增；不得用它认定实际资金用途。[实际分析界面](../../media/showcase/analysis-results.png) · [实际导出的 HTML 报告](exports/analysis-report.html)

## 导出与核对

本目录的 [追踪流水 Excel](exports/tracked-flows.xlsx) 和 [图谱 PNG](exports/traced-graph.png) 均通过上述真实界面下载，未手工重写结果。Excel 含“追踪流水”和“待调取账号”两张表；后者依据本演示的主账号选择生成，不表示现实中的调查建议。

[verify.py](verify.py) 将 CSV 与 XLSX 输入逐格比较，再将导出流水按流水号逐笔核对日期、付款方、收款方、完整账号、金额字符串、币种和摘要：

```sh
.venv/bin/python docs/examples/harbor-path/verify.py
```

[文件核对结果与 SHA-256](verification.json) 记录此次结果。12 笔金额相加为 `1,832,503.00 CNY`，这是跨环节流水的逐笔合计，包含多次转手，不能称为项目资金规模、净流入或损失金额。

样例随项目 MIT 许可提供。CSV/XLSX 是可复现输入；运行时案件与画布 ID 会随环境变化。截图、录屏、公开包和 Windows 实机验收的证据范围分别记录于 [展示核验](../../showcase-validation.md) 与 [桌面交付](../../desktop-delivery.md)。
