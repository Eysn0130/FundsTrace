# 工作区联动与外观设置

本轮从当前 main 移植已确认的主页、案件与导入、账户与身份。全案分析保留现有布局，只补主壳联动。未纳入另一工作目录中的导入解析、资金处置及反馈 ZIP 管线，也未修改交易统计口径。

## 页面与案件上下文

- 主壳是案件选择的唯一所有者；案件页、账户页和内嵌分析页请求主壳切案。消息校验同源、实际 iframe 来源、案件及 generation，旧回调不能覆盖 A→B→A 后的新绑定。
- 主页保留四个 Ribbon Tab、保存/撤销/重做和当前案件/画布。原顶栏操作沿用既有命令入口；56px 左导航集中页面入口，底部保留更新与设置。桌面原生标题栏显示“预览版”，F10/Alt 菜单继续可用。
- 新建案件后立即切入。切回原案件恢复当前会话的画布几何、相机、查询条件、选择及资料输入；图谱事实始终重新读取，未提交写入不自动重放。跨进程重启的未保存工作恢复不在本轮契约内，退出前仍需保存画布。
- 从账户页查看流水采用精确账号条件，保留前导零与字面 `.0`。同名不合并账户，资料只属于当前案件。
- 分析选案与其它页面同步，返回图谱使用原工作区；分析结果生成的独立画布沿用当前 main 的原子创建及追踪接口，写操作经宿主画布保护。案件数据变化后旧结果标记为历史快照、禁用旧结果操作，须显式重新分析。
- 隐藏页返回、导入完成、删批次后刷新所属案件的数据。每案的查询输入与分析参数草稿分别保留，读取结果不作为草稿持久化。

## 写入与恢复

React 导入在 POST 前向宿主申请每案 lease。宿主先预约，再核对导入 session、attempt 和其它资料/画布操作。网络未知结果不解锁、不自动重新 POST；只读核对本次 durable terminal receipt 后释放。确定 4xx 仅在宿主确认 session 仍 ready 且 attempt 未改变时释放。旧窗口不能取消在途写入。

账户身份、照片、主账号、批量资料工具、画布和导入共用必要互斥边界。身份/照片未知操作留在父壳，可重新打开账户页核对；画布未知操作沿用画布管理中的读取与人工确认流程。关闭弹层不等于服务端失败。

金额及 ID 保留字符串边界；统计按币种分别计算。账户新增只读接口使用当前 main 的 flows，未引入其它候选的 effective_flows 或新导入语义。

## 设置与复用

设置包含外观、工作区入口、关于与更新。没有提供尚无实际能力的账户登录、语言切换或通知开关。

- 默认深色 / 蓝色 / 实色；支持浅色、深色、跟随系统，及蓝、青绿、紫、玫红、琥珀五个重点色。
- 修改先预览；取消、关闭和 Esc 还原，保存成功后同步其它文档。恢复默认仅作用于外观，不清理案件或画布。
- `fund_appearance` 是一个 version 1 JSON，严格验证字段和枚举。桌面 Main 原子保存；caption/startup 只接收纯外观快照，窗口位置等私有偏好继续留在 Main。
- `static/appearance.css` 提供 surface/text/border/action/focus/state/material 等语义 Token。Legacy、分析、React 案件/账户和设置控件共用；可嵌入 React 面板通过 `--funds-*` 变量消费宿主主题，CSS 仍限制在 `.funds-trace`。
- 重点色不替换资金角色、资金方向、成功/危险状态、用户图形颜色或导出颜色。画布随应用的已解析主题使用独立图纸调色板：深色保留原样；浅色使用现有 PNG/PDF 的白纸 `#ffffff`、墨色 `#111111` 和浅灰线 `#c9c9c9` 基础。用户自选文字/关系颜色始终优先，节点角色色不变。主题只重绘已有形状的颜色，不重建图谱、重排标签、移动相机、写入画布或占用撤销历史。保存和 HTML 导出的默认样式继续采用既有深色基线，稀疏自选样式保持原值；PNG/PDF 保留原打印契约。浅色采用纸白主背景、暖灰导航、白色资料表面与细边界；选中背景只用少量重点色。
- 半透明是导航与浮层的 CSS 材质，不是整个窗口 opacity，也不是 Win11 原生桌面 Mica。表格、金额、输入及照片保持稳定底色；保留系统减弱透明效果偏好。
- 启动覆盖视图保持原有真实 workbench-ready 和透明交接动画；启动时序变量未作为用户透明度设置。

参考用户设置图的分组、主题卡、重点色及保存/取消结构，并借鉴 Analytix 已有标签/说明/控件对齐语言；未复制 Analytix 业务实现。未找到可确认属于该截图的 GitHub 仓库。公开的 [shadcn/ui 主题文档](https://ui.shadcn.com/docs/theming)、[Dialog](https://ui.shadcn.com/docs/components/radix/dialog) 和其 [MIT 许可](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md) 可作实现参考；本轮沿用原生 dialog 与现有样式体系，没有新增组件框架依赖或声称复用了截图源码。

按本轮追加反馈研究 [Open Claude UI](https://github.com/Caho1/open-claude-ui)（参考提交 c1f923ae0051a871941b98a0e2e3183a545e6a85）的主题、按钮、弹层和动效源文件。借鉴暖中性表面阶梯、单层轻边界、克制阴影及短过渡；本项目自行实现，不导入整个色板或动画依赖。该项目是社区研究，作者的逆向提取说明不作为官方规范或独立验证。其 [MIT 许可](https://github.com/Caho1/open-claude-ui/blob/main/LICENSE) 不涉及 Claude 商标或未分发的专有字体。本轮不复制该品牌、字体或专有资产。

动效白名单限定为按钮/导航的颜色反馈、菜单 160ms/4px 和弹层 200ms/4px 轻入场，以及工作区面板 220ms 过渡；切换设置分类不叠加入场动画。无整页缩放、弹跳或表格行交错入场。图谱、相机、金融数据及导入完成状态不为视觉效果延迟；系统减弱动态效果时关闭这些动画。

追加参考 [Taste Skill](https://github.com/Leonxlnx/taste-skill) 的应用界面研究：采用信息主次、数字对齐、统一控件节奏和即时反馈原则。保留本项目用户已确认的重点色、半透明材质、节点角色语义、完整账号和精确金额；不照搬参考项目的色板禁用、截断 ID 或金额计算建议，不执行其生成脚本，也不新增依赖。页面布局改版仍逐页提供四个方案，经选择后实施。

## 本轮工作区修复与交互

- 主页进入隐藏/inert 状态时，快捷键与直接按钮均不得触发画布撤销/重做；返回主页后恢复。主页的查询与 Ribbon 控件保留原有快捷键行为。
- Ribbon 以自身父槽的实际宽度适配，包含左导航后的剩余空间。父槽为零的隐藏状态沿用最后有效宽度；通过单一 ResizeObserver 接收容器变化，并保留窗口 resize 回退。
- Legacy、分析、React 共用正文/说明/标题、28/32/36px 控件、焦点、圆角、间距和动效 Token；高密度交易表、照片与图谱几何保持各自角色尺寸。嵌入样式仍限制在 `.funds-trace`。
- 账户来源 Tabs 支持方向键、Home/End、roving tabindex 和关联 tabpanel；写入、下载与核对期间提供真实进行中状态，未知结果不重放写入。案件菜单在操作、外部点击、失焦及 Esc 后关闭，忙碌时不可打开；Esc 恢复触发点焦点。
- 原生文件选择能力保留在中文标签之内；弹层关闭后仅恢复可见且可用的触发点，否则回退当前活跃工作区。隐藏页面释放原生弹层，但保留导入控制器中的预览、映射、模式、主账号勾选与在途任务；不重发 POST。真正关闭或换绑定仍沿用原有请求回收边界。
- 导出采样期间延迟图谱换色，导出完成或取消后在首次屏幕绘制前应用最新主题。图例、缩略图、框选/选择轮廓和水印随图纸换色；不改变事实、金额、绑定或保存格式。

## 验证边界与下一步

主页“工作区视图”提供标准、专注和上下分栏；已确认的方案1／4合并为标准及其详情打开状态，不增设第四种布局。入口留在原功能区顶行，收起后仍可用；节点的“布局算法／重新布局”名称及命令保持独立。三态共享同一查询、七列表格与画布，详情抽屉独立。各视图保留当前会话的收起、筛选与表格滚动状态，切换不改变查询草稿、锚点或上图状态；分栏高度随实际槽位重夹取。具体行为见 [工作区方案](graph-workspace-plan.md#工作区视图)。

自动回归覆盖案件隔离、精确金额/账号、照片、查询、A→B→A、迟到请求、导入未知回执、主题持久化及桌面消息边界；Chrome 使用独立合成数据库检查四页导航、选案、深浅主题和设置保存/取消。没有访问业务数据库或修改原工作目录。

下一步优先在 Win11 实机核对 100%/125%/150% DPI、原生标题栏、F10、文件对话框、启动交接与更新控件；再做安装包候选的升级/保留验收。源码合并不代表已经打包、签名或发布，也不代表完成 Win11 安装态验收。
