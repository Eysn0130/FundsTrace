## 行为和实现

整包预览为来源位置和来源范围增加少量派生字段时，原实现会重新压缩、写回整条流水与来源记录。现在只在操作专属 SQLite 暂存中写入这些字段，读取时还原完整对象。普通后续修改仍写回完整有效记录并消耗增量覆盖；旧引用、明确删除、重新绑定、取消记录及稀疏来源位置保持原语义。关闭操作即释放暂存，不增加可恢复的业务状态。

打包备注在序列化时只读取一次，避免通过 Mapping 为每个字段反复读取同一备注。预览来源样本使用既有来源编号索引；前十项未决示例使用已有分类选择器，保持来源顺序与上限。

没有改变原件、来源位置、Decimal 金额、微秒、身份/事件规则、前端操作、持久数据库、API 或 `.fundcase`。暂存覆盖只允许闭合的字符串字段，损坏覆盖拒绝读取；失败不能留下已提交的部分案件。
