# 图谱分级、邻域与交互基准

## 当前选择、群移与光圈（2026-10-15）

施工范围为新版 FundsTrace 的 G6 画布，旧版 fund-tracker 与 Analytix 未修改。`static/graph-selection.js` 管理当前绑定的选择和移动；选择是临时交互状态，不进入画布文件或撤销快照。

- 普通单击节点或连线只更新选择，供功能区编辑样式；通过功能区固定的“查看详情”入口，或图谱本身聚焦时按 Enter，显式打开账户详情／资金流向。Ctrl/Command 点击增减节点选择，不请求详情。图谱获得焦点后，Ctrl/Command+A 选择当前图中全部节点，Escape 或单击空白取消。输入框、弹窗及图谱外的快捷键不被接管；撤销恢复忙碌期间禁止新选择和拖动。
- 选中总数为 1–10 时，可见节点有呼吸光圈；11 个及以上全部静态，回到 10 个即恢复。静态描边保留角色填色、照片和主账号标记，照片另有一个无动画轮廓。光圈最多 10 个，用 CSS 动画；没有常驻 JavaScript 帧循环、全图 G6 动画或模糊阴影。遵守系统减少动态效果，页面隐藏时停止呼吸。
- 光圈通过 G6 的真实坐标变换跟随缩放、平移、布局和节点移动，尺寸与缩放同步；离开视窗的光圈移除。显示照片等重建保留当前有效选择和视角；切换案件/画布清除旧选择、详情与手势。
- 拖动已选节点移动整组选中节点；拖动未选节点改为移动该单个节点。屏幕位移达到 4 px 才开始，单击不建立移动历史。少于 50 个实时更新所选节点及关联边；50 个及以上只移动一个整体预览框，过程中不写节点坐标，松手一次批量提交和一次撤销记录。已开始拖动时忽略 G6 提前发出的节点／空白点击，由全局 mouseup 完成。失焦、移出窗口、页面隐藏或发现主键已释放，均保留最后合法位置；Escape 明确取消才恢复原位，失效绑定不向新画布提交。
- 群移同时平移两端均选中的手工折点；仅一端选中的边保留折点。标签沿原路径比例恢复。撤销/重做恢复几何及视角，保留仍在当前图中的选择。

同时修复了同案详情请求乱序/关闭后回填、重建后失效 Item、选择点击产生移动历史、预览提交晚于撤销记录、重复全局边线监听器、边线命中半径随缩放失真、以及边线拖动跨案件/画布/视图绑定写入旧位置的问题。边详情在没有节点选择时也能用 Escape/空白关闭；同账户重绘保留编辑焦点和保存反馈。节点点击快速路径仍经过撤销/布局忙碌拦截，自定义手势保留原始事件的取消能力。

### 2026-10-17 详情与选择分离

资金流向采用图1右侧非模态抽屉，280ms位移过渡，层级30高于缩略图12，并遵守减少动态效果。它不抢占背景画布的编辑语义。展开与收起功能区都有同一显式详情入口；空选、多选、拖动、布局／载入／历史忙碌时入口禁用。Enter仅在图谱容器本身聚焦、无修饰键、非输入／组合输入、无模态层时触发，不接管输入框的Enter。

单击不启动详情请求，也不延迟选择以等待可能的双击；4px拖动阈值、尾随点击屏蔽、群移和撤销边界保留。节点双击仍展开邻域，连线双击仍只在折点附近删除折点，不将同一双击再分派为查看详情；右键保留系统菜单。手动关闭详情保留当前节点／连线选择并还焦图谱，空白单击／图内Escape才清除选择。按抽屉内Escape关闭行菜单后还焦触发器，再按Escape关闭抽屉，避免同时穿透两个层级。

选择的保存与详情开关独立：样式重绘后从新图元映射重新绑定所选关系，不能保存已销毁的G6 Item；不因抽屉未打开而丢失边选择。逐笔“前后流水”保留原上下文，移出图谱继续使用现有受控命令及撤销；成功后沿用该命令关闭详情的行为，原始流水保留。行菜单在表格／正文滚动和窗口变化时撤销，避免误操作已滚走的原行。读取返回数与实际总数分别显示；接口上限500时不暗示已经展示全部记录。

### 第二轮实际交互验收

在新版隔离合成环境复现并修复两处问题：拖动松手后的 400 ms 屏蔽误吞下一次独立点击；节点按下尚未跨过拖动阈值时启动撤销，继续移动可绕过忙碌检查，撤销失败后留下未记录位移。修复让新的合法原生 mousedown 解除旧尾随 click 屏蔽，同时在待定手势的 move/up 重新检查交互许可。同一次拖动派生的尾随 click 仍被抑制。

本轮实际 Chromium 155、1280×900、DPR 1，hub、seed 2026，使用 120 与 5000 节点。120 节点的两个案件具有相同节点 ID，另建立一个含完整合成图的独立保存画布，检查案件/画布 A→B→A 的恢复。验收结果：

| --- | --- |

以下保留第一轮标签/邻域候选及其性能证据；当前绘制已改为按需创建标签、视窗裁剪与缓存缩略图，见 [大图绘制](graph-viewport.md)。下面“隐藏文字形状”和旧源码指纹属于当时实现，不代表当前候选。

## 显示与保存语义

- 标签模式为“自动分级 / 仅关注邻域 / 全部标签”。自动模式中，20 个账户以内显示全部标签；更大图按相对适应画布的缩放级别限制为 20 / 80 / 160 个账户标签和 0 / 40 / 80 个关系标签。选中的关系在概览也保留一个标签，选中和悬停账户优先。“仅关注邻域”不补充无关账户，“全部标签”明确解除限制。
- 分级只隐藏 G6 文字形状，原始 `model.label`、精确金额字符串和分币种汇总保持完整。缩放结束后延迟 140 ms 重施标签策略，避开 G6 4.8.19 内置的 100 ms 恢复操作；不在每个滚轮事件中重建图谱。
- 输入完整中心账号或从账户详情进入，按双向、转入或转出查询一跳邻居，每批最多新增 50 个。重复展开继续读取当前中心的剩余邻居；双击其他节点可继续围绕它展开。界面同时显示可见/完整账户与关系数，以及尚未展开的数量。
- 邻域是显示过滤。隐藏账户不会被取消追踪，返回全图恢复完整集合。“另存为 / 存形”保存完整图；PNG、PDF、HTML 图谱导出仅含当前视图。HTML 有明确范围提示，并携带 `view` 计数与 `labelVisible`；服务端校验计数，旧版无 `view` 的请求仍可使用。
- 调阅快照保留每条边的线型、折点和标注位置；线型框显示“已保存线型”，选择任一普通线型会统一应用。逐边覆盖随撤销／重做恢复，清空失败补偿也须恢复。照片采集期间形态失效会中止保存／另存；有效空图仍可保存。PNG／PDF 共享画布采样串行，完成或取消后恢复原尺寸与相机。
- 案件、画布与同画布重新绑定使用 generation 撤销布局、标签定时器、导出、照片和异步详情。切换期间不能让旧展示变成新绑定的数据；完整图缓存与显示过滤必须一起失效。

G6 行为依据为固定版本的 [缩放处理](https://github.com/antvis/G6/blob/4.8.19/packages/pc/src/behavior/zoom-canvas.ts#L179-L267)、[画布拖拽](https://github.com/antvis/G6/blob/4.8.19/packages/pc/src/behavior/drag-canvas.ts#L182-L263) 和 [节点拖拽](https://github.com/antvis/G6/blob/4.8.19/packages/pc/src/behavior/drag-node.ts#L31-L45)。这些是现有版本的行为依据，不是升级到 G6 5 的承诺。

## 可重复入口与指标

```sh
.venv/bin/python scripts/preview_synthetic.py --graph-nodes 1000 --graph-shape hub --graph-seed 2026
```

访问入口打印的 `/synthetic/graph-benchmark?case_id=2&label_mode=auto`，与 `label_mode=all` 对照。把 `--graph-nodes` 改成 `5000` 做容量观测；`--graph-shape chain` 提供链图。每个参数指定的是实际账户数，关系数为账户数减一。两份案件使用相同账号、不同金额，另有空案；金额包含超过 JavaScript 安全整数范围的分位、0.01 和 USD/CNY。临时目录和许可均为公开合成材料，退出后清理。

只有此合成预览路由注入计时脚本。生产首页不加载记录器。面板可下载 JSON，保留数据种子、金额期望、源文件 SHA-256、窗口、浏览器环境、每个原始样本及丢弃计数；不上传、不记录账户或流水内容。正常应用模块也不注册此预览路由。

| 指标 | 起点 → 终点 |
| --- | --- |
| 请求到首绘代理 | `/api/graph` 请求前 → 首次 G6 数据提交后的下一次 RAF 回调实际执行 |
| 导航到首绘代理 | 文档 `performance.timeOrigin` → 同一 RAF 回调 |
| 布局完成 | 图请求前 → Worker 布局结果落位并提交绘制 |
| 交互延迟代理 | 最新匹配的 DOM 输入时间戳 → G6 提交后的下一次 RAF 回调实际执行 |
| 事件处理等待 | DOM 输入时间戳 → capture listener 收到输入 |
| capture 到提交 | capture listener 收到输入 → G6 交互事件通知 |
| RAF 最大间隔 | 输入等待或拖拽活动期间相邻 RAF 时间戳的最大间隔 |

滚轮只与真实 `wheelzoom` 对应，节点/画布拖拽按 G6 实际事件区分；适应画布等程序调用不会计为用户输入。一次提交可能合并多条输入，JSON 明示合并数。中位数和 P95 均使用 nearest rank；少量样本的 P95 常等于最大值，不能推断长期尾延迟。

RAF 回调读数使用 `performance.now()`。同一帧的多个 RAF 回调收到的参数可能相同，即使前面的计算已耗时；直接把该参数作为终点会低估延迟，见 [MDN 的时间戳说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)。这些指标是浏览器回调代理，不是显示器实际呈现、输入到光子延迟或 FPS。采样时必须串行，暂停构建、测试和其他性能任务，固定窗口、数据和源码；任何可执行源码修改后重启合成服务并重测。

## 2026-10-16 候选：标签与交互一致性

前一轮候选在 G6 4.8.19 上新增文字与主体障碍的空间网格避让、候选位置及显示引导线；这些引导线与标签底板已由下述纯文字策略取代。节点完整姓名可换行，账号和金额不经浮点缩写。完整多选集作为 focus 上下文，auto／focus 依然受 20／80／160 密度预算约束，显式 all／图片导出保留全量标签。

节点角色、主／同名身份、用户边框与瞬时选择分层。节点样式／字体操作保持相机与位置；“更多→按文字整理布局”才主动腾出布局空间。选中关系的线型操作只改该关系，并只记录一条历史；没有选边时禁用。多选格式显示混合值，边选择有准确状态提示。

### 已确认样张：纯文字与本线中段留缝

节点和关系标签均无底色、边框、文字描边及引导线。节点文字只有一个锚点：与主体实际屏幕包络水平居中，文字顶边在主体包络底边下方 6 CSS px；阴影、照片、强调尺寸、多行文字和字体均以实际包络测量。缩放只改变文字大小，不改变这段屏幕间距；碰撞处理只能控制 auto／focus 的可见集合，不能把节点文字挪到顶部或侧面，all 仍保留全部。关系标签只受用户的 auto／focus／all 范围控制，不因碰撞隐藏或移动到别处。复杂关系允许相互遮挡，保留所属连线的中段位置；显式手工拖动仍按完整路径比例恢复。

简单图要求完整追踪图最多 24 个节点、30 条边、无向最大度数 5，且无自环、平行／反向重复、无向环；完整坐标存在时还排除非共端点交叉、重叠及零长关系。筛选／邻域只改变展示范围，不能使原复杂图升级为简单图。符合条件且未人工修改的默认曲线统一向屏幕右侧拱，近水平时平直；source／target 和箭头方向不变。人工线型、控制点不受覆盖。

简单图中实际切线斜率绝对值不超过 0.12 的关系，文字居于真实中段上方；其余情况文字水平置于本线中段。文字与线条留 4 个图坐标单位间距，随图谱缩放。中段留缝仅裁剪所属关系的可见副本和选中外圈；完整透明 keyShape 保留命中、路径比例和箭头几何，其他关系不会被擦除。隐藏／空标签恢复完整线条。拖动节点、改线型／字体、缩放落定和图片采样时重新计算。

新快照以 `routeManual` 区分自动路线与人工覆盖，避免复杂布局保存重开后将自动线型冻结；旧快照继续保守保留原人工几何。PNG／PDF 共用主画布采样，HTML 内联同一纯文字几何模块，并在拖动后重算复杂度；局部导出携带来源图的自动路由资格。顶栏结构、画布区域与持久化金额事实保持不变。验证使用隔离合成数据，不代表真实案件、大图性能或发行验收。

快照保留有效字体、nodeStyles、手动路径比例及新旧manual标记。新画布保存不嵌照片，重开读取当前案件照片；HTML默认嵌导出时照片。相机／邻域重开仍按原完整图谱与fit语义处理，不宣称逐像素恢复；同视图内的字体、几何及金额编码契约可验证。PNG／PDF采样事务清理瞬时装饰，迟到recent回调待采样完成后才应用，旧绑定回调失效。

以上修改后的功能与复杂度回归属于新候选；上面的旧5000图计时不作为本次性能结论。

### 微拖与标签锚点回归

真实 G6 预览中，6×2 CSS px 微拖已跨自定义阈值，但 G6 在 canvas mouseup 阶段仍会先发 node:click，原点击处理通过选择操作取消在途拖动，造成回跳并打开详情。10×8 px 拖动不一定触发，因此单独测试点击或大幅拖动不能覆盖此缺陷。回归明确模拟 node:click／canvas:click 先于 window mouseup，覆盖单选、多选及 50 节点预览、0.4／1／2 倍缩放；断言不打开详情、不清空选择、不回滚、只完成一次。另覆盖丢失 mouseup、失焦／离窗／隐藏、Escape 与旧绑定迟到事件。

Fit 只写相机；从相同倍率起点在单次命令内有界计算固定屏幕间距的最终文字包络，避免连续 Fit 逐次漂移。PNG／PDF 采样按导出倍率放大间距，恢复后重新锚定；HTML 使用同一 placeNode，忽略旧 labelOffset 的侧向／上方偏移。自动回归还验证移动 → hover → 缩放 → Fit → 撤销／重做的组合序列；保存重开与离线导出另有公共接口检查。这些结果不代替真实案件或 Windows GUI／DPI 验收。

### 系统组合验收与后续修复

五种布局分别对分支、循环、枢纽、断开重合点、交织图执行布局 → 微拖 → zoom／重复 Fit → undo／redo → 追加 → membership undo／redo → 快照重开，共 25 条组合链；逐步断言原始方向／精确金额、节点标签锚点及关系文字所属路径。边折点／标签共用主键及忙态门禁、终止与取消规则；丢失 mouseup、失焦、离窗、页面隐藏完成最后合法编辑，Escape 回滚，正常完成只写一条历史；切案、销毁和 A→B→A 后的旧事件失效。

大图 force 移除原来的 viewport 硬夹，并与小图一样接收完整文字占位。保留近场／远场迭代，末段有界空间查询，无解时向已占包络外移动；世界坐标可以扩展，Fit 负责相机。当前 81／400／1001 合成几何回归不代表同规模所有文字首屏可读；最终候选没有 5000 低延迟结论。

重开画布只拥有一次未被改变的初始视图适应意图。有时间窗口时先等待对应投影完成，不在读取中的空占位上 Fit；投影就绪后按当前可见图适应，已有坐标、固定位置、折点和手工文字比例保留。若用户调整相机／zoom、开始新布局、切换绑定或显示范围，或正在 PNG/PDF 采样，旧意图不得再 Fit；普通时间窗口编辑和播放帧也不重新取得开图的相机权限。导出把 G6 的 null matrix 作为合法 identity 恢复；仅缺少相机 API 的旧宿主走原适配回退。页内脚本缓存版本随适应逻辑同步更新，避免混用新旧控制器。

### 2026-10-17 · 账户资料图1

账户资料与资金流向共用显式详情入口：单击只选择，拖动仍移动，双击保留原邻域／折点语义；选中单个账户或关系后，使用功能区“查看详情”，或在图谱容器本身获焦时按 Enter。关闭抽屉保留选择并还焦图谱，输入框中的 Enter 不穿透到图谱。账户抽屉从右侧滑入，层级高于缩略图，系统减少动态效果时取消位移动画。

身份证号与重点展示分别显式保存；未保存值只驻留内存，关闭重开、同一绑定重绘及切换账户可恢复。切换案件／画布、新建、另存为及新建案件前，存在草稿则先确认；取消保留原绑定与草稿，确认离开后清理。已命名画布的原位保存不离开绑定。账户写入与照片裁剪互斥，并跨账户串行；保存失败保留草稿。迟到读取／写入按案件、画布代际及视图绑定校验，不把旧资料或反馈写到新范围；同一范围内已成功的写入刷新真实图谱事实，不强制重开被关闭的抽屉。失效的裁剪可关闭并重新打开，不继续提交旧绑定。

“本案件／当前图谱”仅切换交易统计；交易对手 TOP20 明示为本案件，沿用接口排序。金额保留完整字符串并按币种分别展示，图谱统计合并同一笔流水的双方镜像。查看流水清理旧筛选后查询账户或双方组合，并展开查询区。表格复用共享横滚组件，行操作固定在右侧；菜单在滚动、失焦或 Escape 时收起，Escape 每次只处理当前一层。

照片保留上传、原图重新裁剪、键盘调整和确认移除。移出图谱需确认当前相关已追踪流水的去重数量，调用原受控命令，支持原撤销；不删除案件源流水，确认期间相关流水集合变化则要求重新确认。上述行为由合成浏览器及账户公共行为回归覆盖，结果与范围见 `design-qa.md` 本轮账户资料验收。


## 2026-10-18 自动弧线与箭头状态

自动二次曲线使用两端点局部方向及有限法向偏移，替换旧固定向屏幕右侧的控制点；双向关系分道。简单拓扑同样进入有限避障评估；清晰短弧不展开候选搜索。标签阻塞才增加端点文字包络推导的候选，候选与工作预算有界。手工线型、折点和标签比例继续优先，不写交易事实。

路由验收复用实际路径采样及真实文字包围盒。除七类碰撞计数不增加，还按冲突对象身份防止跨节点、跨关系抵消；同一关系对的交叉点移动不算新增冲突，多次交叉仍逐个计数。缩短验收按本次实际改变的关系长度计算，不能被无关超长关系稀释。缺少真实测量、身份或完整预算时保留原路线。

合法节点移动仅在提交前对关联自动边规划一次，不在逐帧、单击、取消或重复G6结束事件中规划。路径与节点在同一条历史中撤销/重做，相机保持。离线HTML沿用同源模块；完整拓扑才迁移，部分拓扑/手绘保留，拖动帧仅连续跟随，结束后才做有限实际验收。

这套策略优先清晰短路径，避障必要时弯曲；不是任意密度/任意文字长度的全局最优保证。超过当前几何容量的标签保留完整内容和空间不足提示，不能为零碰撞指标截断金额或改动节点位置。当前本地合成证据和压力场景余留见 design-qa.md。


## 邻域与明确搜索定位（2026-10-18）

邻域追踪复用顶栏二级表单浮层。左侧是待应用的中心和方向，右侧是已应用邻域。预计规模与实际显示均使用完整追踪图的一跳邻域，再组合关系金额、隐藏账户和仅显示账户条件；方向选择邻居，不删除入选账户之间的已有关系。初次最多50个邻居加中心；继续展开只使用已应用中心和方向，每次再取最多50个，不读取方向草稿。返回全图保持原语义：清除邻域及图内显示筛选。

明确搜索或选择候选才预览相机；输入仅更新预计。完整账号精确优先、保留前导零；模糊账户或户名有多个候选时要求选择。流水查询按钮和非IME Enter在包含账号/户名/交易对手时定位图内匹配账户，独立字段保持原交易查询的OR参与方语义；多结果整体定位，超过100个提示补全条件。日期、金额、摘要、翻页、重置、后台刷新不抢相机。主账号防抖只更新候选，明确搜索唯一结果或点击行内SVG定位才预览；定位不设置主账号。

相机默认320ms缓出，定位节点自身到未被浮层、抽屉、缩略图等遮挡的可用区域中心。账户预览在低倍率时以0.85为可读目标，仍受图谱上限、节点文字包络及实际空间约束；聚焦选中保留原2倍适应上限。减少动态效果设置使用立即定位。明确搜索在等待查询前获取相机意图，新搜索、手动画布、实际尺寸变化、历史恢复、上下文切换和导出使旧动画失效。零延时初始Fit、快照迟到Fit和后台布局都检查相机意图，避免覆盖用户操作。

单个或少量搜索结果的标签临时获得可读优先级，不加入选中集合、不打开资料、不写历史或保存设置；画布手势、选中变化和重绘清除该优先级。范围外或未上图账户提示原因，保留相机和筛选，不自动清条件或追踪原始数据。搜索令牌同时校验案件/画布代次、图和视图实例、显示revision、相机意图与矩阵；输入变更、迟到查询及A→B→A切换不会挪动当前画布。

应用邻域继续通过现有CanvasEditor历史边界，等待相机完成后采集操作后快照；资料草稿、写入、裁剪、确认、布局和忙态阻止应用。共享浮层处理Esc、焦点及完整的首次画布关闭手势，避免关闭后同一手势触发节点选择或拖动。
